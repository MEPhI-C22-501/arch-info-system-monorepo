Внутренние события не получают Kafka-топик и не публикуют черновики.
ProjectCreated/Changed и AllocationChanged остаются внутренними: действующая
структура/назначения передаются с Publication активированной версии.
TaskDeleted — дополнение для явного удаления, не вывод из отсутствия на странице.
Для всех внешних событий обязательны at-least-once, inbox/outbox, повтор без
дубликата и DLQ при исчерпании попыток. High означает оперативный разбор сбоя,
а не гарантированный отдельный класс Kafka QoS.

обоснование выбора транспорта — [162](162.integration-spec.md).
