# 150 — Компоненты Planning System

Редакция 1.1, 18.10.2026. C4 Component исполняемой поставки, [ADR-016](145.architecture-decisions.md#adr-016).
[Логические потоки](146.logic-scheme.md), [развёртывание](165.deployment-diagram.md).
API и worker собираются из одного образа; браузер получает статические файлы API.
Пунктиром показаны ещё не подключённые адаптеры общего стенда.

| Компонент | Технология / файл | Ответственность и состояние | ADR / требования |
| --- | --- | --- | --- |

| Portfolio / Project | Python, app.py / runtime.py | CRUD проектов, программы, фильтры, пагинация, архив | 003; FR-01 |

| Forecast | Python, domain.py / app.py | Факт + ручной ETC, стоимость и PARTIAL; сейчас синхронно в API, отдельный worker остаётся целевым | 002/011/016; FR-08/10 |

| Publication worker | Python/httpx, worker.py | Сохранённые операции публикации, retry/receipt; TT mapping требует принятия | 004/008; FR-11/12 |
| Repositories / audit | SQLAlchemy/psycopg, storage.py + migrations | JSONB snapshots, revisions, транзакции; PostgreSQL-триггеры baseline и аудита | 003/005/015; NFR-04/05/14 |
| HR sync | Целевой Python REST adapter | Чтение HR/НСИ, resource name/etag и rename; пока fixture-входы, реальный adapter не поставлен | 010; INT-02 |
| Kafka / Notification policy | Целевые Python adapters | Broker/inbox/outbox, DLQ и доставка адресату; код их сквозной стыковки ещё не поставлен | 004/008; INT-03/04 |

Unit/API-тесты проверяют расчёты, права, повторы и переходы. Browser E2E проверяет
планирование, конфликт, согласование, сценарий и вложение на локальном сервере.
Реальные T-INT, полный рабочий календарь, нагрузка и restore общего стенда —
отдельные проверки [095](095.requirements-check.md)/[160](160.integration-plan.md).
Наличие dev-модуля не подтверждает готовность целевых адаптеров. CI, seed, Compose,
minikube и безопасность перечислены в [165](165.deployment-diagram.md).
