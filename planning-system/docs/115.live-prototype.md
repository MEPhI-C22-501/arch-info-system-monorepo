# 115 — Кликабельный прототип

Редакция 1.0, 05.10.2026. Один [index.html](../ui/prototype/index.html):
12 связанных экранов, встроенные CSS/JS, без внешних библиотек и сетевых запросов.
Открыть файл в браузере либо из корня репозитория выполнить
`python -m http.server 8000` и открыть
`http://localhost:8000/planning-system/ui/prototype/`.

## Что реализовано

Навигация с URL hash, переключение шести ролей, статусы loading/empty/error,
редактирование названия/часов/даты, сохранение в localStorage, проверка ресурсного
конфликта, ресурсное подтверждение, submit/return/approve/activate, изолированная
копия сценария, личный календарь active baseline, демо-вложение и повтор обмена.
Кнопка сброса с подтверждением возвращает исходный набор. Данные синтетические.

| Сценарий | Шаги | Проверяемый результат |
| --- | --- | --- |
| Годовое планирование | R-02: портфель → декомпозиция, изменить название → потребность 6 ч → ресурсы | Поля сохранены после перезагрузки, родительский итог не удваивает часы |
| Конфликт ресурсов | В начале 6 ч назначения / 4 ч доступности → конфликты; R-04 → доступность 6 ч → подтвердить | Перегрузка 2 → 0; отправка доступна только после подтверждения |
| Согласование | R-02 → отправить; R-01 → вернуть с комментарием; R-02 → повторить отправку; R-01 → утвердить → активировать с подтверждением | Round увеличивается, ON_REVIEW/APPROVED не редактируются, появляется baseline |
| Перепланирование | После активации R-02 → сценарии → копия → поменять дату; R-04 → подтвердить → R-02 отправить → R-01 утвердить/активировать | Старая baseline не меняется до новой активации; V2 становится активной |
| Ошибка обмена | После активации R-06 → журнал → повторить | Демонстрационное FAILED → SUCCEEDED, ключ сохранён, baseline не изменена |
| Отказы и роли | R-05 → календарь/вложения; выбрать loading/empty/error → повторить | Чужие рабочие разделы скрыты, ошибка не маскируется пустыми данными |

## Ограничения

Это UI-прототип, не сервер: нет JWT/реального RBAC, CRUD нескольких проектов,
пагинации большого набора, расчёта рабочего календаря/FS, обмена Kafka/REST/S3,
загрузки файлов, денежных прав или настоящего согласования несколькими людьми.
localStorage доступен владельцу браузера. Метки AVAILABLE/SUCCEEDED в демо
не подтверждают внешнюю операцию. Истинные правила — 050/070/130/140.

Дизайн всех экранов и трассировка — [110](110.ui-ux.md). Прототип проверяется
сценариями из таблицы; интеграционные T-INT и пентест приложения остаются planned.
