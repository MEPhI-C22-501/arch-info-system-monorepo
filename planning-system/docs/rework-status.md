## Что ещё не выполнено

Нет серверного приложения, БД/миграций, Docker Compose, workflow выпуска,
unit/контрактных/E2E-тестов приложения, отчёта проверки безопасности,
манифестов minikube и исполняемого demo seed. Это [TECH-01…06](165.deployment-diagram.md#обязательный-backlog-реализации),
а не часть завершённого комплекта проектирования. Реальные интеграции с
Keycloak, Reference Manager, Task Tracker, Notification Service, Object Storage,
Reports и QA не проходили сквозную приёмку. Конкретные зависимости и критерии
проверки зафиксированы в [160](160.integration-plan.md) и [095](095.requirements-check.md).
