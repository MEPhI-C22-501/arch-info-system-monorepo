# Planning System

Черновой комплект документации для подсистемы портфельного, ресурсного,
календарного и финансового планирования проектов.

Подсистема задумана как уровень управления **выше обычного task tracker**:
task tracker отвечает за исполнение задач, а Planning System связывает стратегические
цели, портфель проектов, финансирование, доступность людей, календарные ограничения,
сценарии и план-факт.

## Состав комплекта

- [Vision](docs/vision.md) - краткое видение, процессы, требования и интеграции;
- [Техническое задание](docs/technical-specification.md) - предварительная редакция
  по структуре ГОСТ 34.602-2020;
- [Ландшафт всей системы](docs/system-landscape.md) - границы Task Tracker,
  Planning System, справочников, отчетности и инфраструктуры;
- [Архитектура и диаграммы](docs/architecture.md) - C4, UML, модель данных,
  состояние плана и ключевые сценарии;
- [Реестр открытых вопросов](docs/open-questions.md) - сведения, которые должен
  подтвердить заказчик до утверждения ТЗ;
- `docs/diagrams/` - отдельные Mermaid-исходники диаграмм.

## Граница подсистемы

Planning System хранит проекты, версии планов, сценарии, мощности, назначения,
бюджеты, источники финансирования и прогнозы. Задачи, их workflow, канбан-доска и
детальные трудозатраты ведутся в смежной подсистеме Task Tracker и синхронизируются
через API и события. Общие классификаторы берутся из Reference Manager.

## Статус

Версия `0.2`, концептуальное ТЗ. Значения, помеченные как предварительные, и пункты
из реестра открытых вопросов должны быть согласованы с заказчиком. Документ пока не
является утвержденным ТЗ и не содержит подписей сторон.

## Просмотр диаграмм

Диаграммы встроены в `docs/architecture.md` в формате Mermaid и отображаются в
интерфейсе GitHub. Файлы `docs/diagrams/*.mmd` можно редактировать отдельно и
рендерить Mermaid CLI или совместимым IDE-плагином.
