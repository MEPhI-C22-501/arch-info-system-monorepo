# Planning System

Финальный комплект документации системы портфельного, ресурсного и календарного
планирования проектов.

Planning System хранит проекты и версии планов, выполняет годовое и скользящее
планирование, рассчитывает потребность в людях, строит календарь и формирует единый
прогноз оставшегося времени и бюджетных корректировок.

## Документы

- [Vision](docs/vision.md) - назначение, процессы, архитектура C4/UML,
  интеграции и владение данными;
- [Техническое задание](docs/technical-specification.md) - финальные требования;

Диаграммы встроены в документы и отдельно хранятся в `docs/diagrams/` как
Mermaid-исходники.

## Ключевая граница

Planning System является мастер-системой проектов. Она передает проекты, структуру
работ, сроки и назначения в Task Tracker. Task Tracker хранит задачи и возвращает
события об их создании и изменении, статусы, историю и фактическую трудоемкость.
Обмен задачами выполняется только через API и события.
