# Проверка безопасности модуля: чек-лист и отчёт

> Артефакт вне нумерации комплекта 010-165. Требуется по NFR-RM-50: проверка безопасности по чек-листу (XSS, CSRF, инъекции) и краткий отчёт о результатах.
> Источник - [системные требования, раздел 10.8](system-requirements.md), [NFR](075.nfr.md), код и конфигурация в `main`.

## 1. Состояние проверки

| Параметр | Значение |
| --- | --- |
| Дата | 2026-10-02 |
| Что проверялось | Код и конфигурация сервиса в `main` (коммит `4a9640d`), прототип интерфейса `ui/prototype/index.html`, Dockerfile, Compose, workflow CI |
| Чем | Просмотр кода и конфигурации, поиск по репозиторию. Динамических проверок и сканеров не было |
| Полнота | Частичная. В коде есть каркас сервиса и две служебные точки. Методов справочников, проверки токена, обращений к Keycloak и интерфейса как компонента ещё нет, поэтому их проверка перенесена: пункты отмечены "не проверялось" с условием проверки |

Отчёт повторяется перед приёмкой (веха M5) на развёрнутом в minikube модуле. Тогда все пункты должны получить результат, а замечания уровня "высокий" должны быть закрыты.

## 2. Чек-лист и результаты

Результат: "пройдено", "замечание" или "не проверялось".

### 2.1. XSS

| № | Что проверяется | Как | Результат |
| --- | --- | --- | --- |
| X-1 | Значения записей выводятся в интерфейсе как текст, а не как разметка | Просмотр шаблонов прототипа | Замечание З-1: значения полей проходят через функцию экранирования, но идентификатор записи и имя записи вставляются в разметку без неё |
| X-2 | Статика интерфейса отдаётся с `Content-Security-Policy` без inline-скриптов и `X-Frame-Options: DENY` (NFR-RM-35) | Просмотр прототипа; заголовки ответа | Замечание З-2: прототип - один файл со встроенными скриптом и стилями, с таким заголовком он не заработает. Заголовки не проверялись: компонента интерфейса нет |
| X-3 | Ответы API имеют тип `application/json` и не отражают ввод в виде разметки | Запросы с разметкой в полях и фильтре | Не проверялось: методов справочников нет. Проверить контрактным тестом в срезе 1 |
| X-4 | Файл выгрузки не исполняет формулы из значений полей | Выгрузка записи со значением, начинающимся с `=`, открытие в Excel | Не проверялось: выгрузки нет. Проверить в срезе 1 вместе с NFR-RM-45 |

## 4. Вывод

Из 22 пунктов чек-листа пройдено 5, по 8 есть замечания, 9 не проверялись, потому что проверяемой функциональности ещё нет. Замечаний уровня "высокий" два: пароль в репозитории и отсутствие проверки токена. Оба должны быть закрыты до выпуска первой версии. Модуль в текущем состоянии проверку безопасности не прошёл. Повторная проверка выполняется на развёрнутом модуле перед приёмкой.
