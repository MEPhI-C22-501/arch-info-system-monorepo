## 1. Люди

| ID | Актор | Должность или роль в предметной области | Действия в системе | Роль доступа |
| --- | --- | --- | --- | --- |
| H-01 | Администратор справочников | Участник команды справочников, отвечает за содержание общих классификаторов | Создаёт записи классификаторов, исправляет наименования и поля, удаляет ненужные записи, восстанавливает удалённые, читает историю, выгружает справочники, наполняет новый справочник начальными данными; работает через интерфейс администрирования или API | R-02 `reference-admin`: create, read, update, execute, delete на классификаторах; read, execute на кадровых справочниках |
| H-02 | Читатель | Сотрудник, работающий в подсистемах ERP: бухгалтер, планировщик, руководитель проекта, аналитик отчётов | Выбирает значение справочника в форме своей подсистемы, просматривает справочник и историю записи, выгружает в `.xlsx`; в сервис напрямую обращается только через интерфейсы подсистем или выгрузку | R-01 `reference-reader`: read, execute; оклады и отсутствия недоступны |
| H-04 | Инженер справочников | Разработчик сервиса, владелец кода | Реализует справочники из состава первой версии: хранилище, коллекцию и методы, схему в спецификации, тесты; выпускает новые версии сервиса | R-03 на уровне репозитория; в API - как H-01 |
| H-05 | HR-администратор | Сотрудник кадровой службы, отвечает за HR-профили и организационную структуру | Принимает сотрудника: создаёт HR-профиль, после чего сервис создаёт учётную запись. Назначает на должность, задаёт оклад, отмечает отсутствие, увольняет. Ведёт подразделения и должности. Повторяет незавершённую операцию с учётной записью. Работает через интерфейс администрирования или API | R-04 `reference-hr-admin`: create, read, update, execute, delete на кадровых справочниках, включая оклады и отсутствия; read, execute на классификаторах |

H-01 и H-04 обычно одни и те же люди; разделены, потому что первый действует через API и интерфейс, второй через репозиторий. H-05 в команду справочников не входит. H-03 (команда-заказчик) отозван 2026-09-27.

## 2. Внешние системы

| ID | Система | Протокол и сценарий интеграции | Что делает по отношению к сервису |
| --- | --- | --- | --- |
| S-01 | Сервисы-потребители: Core, Task Tracker, Planning System, QA System, Reports | REST/JSON под `/v1` с Bearer-токеном сервисной учётной записи; `List` с фильтром, `Get` по имени, чтение истории; кэш на своей стороне. Роль `reference-reader`, а потребителям окладов и отсутствий - `reference-hr-reader` | Только читают. Не создают и не изменяют записи, не подписываются на события: их нет. Задание ETL команды Reports извлекает справочники тем же способом для аналитического хранилища |
| S-02 | Keycloak | OIDC: пользователи входят через Authorization Code с PKCE, сервисы получают токены по client credentials, сервис загружает открытые ключи по JWKS или получает их из конфигурации (вопрос 7). Admin REST API: сервис под служебным клиентом `reference-manager-provisioner` создаёт, изменяет и блокирует учётные записи сотрудников | Выдаёт токены с ролями. Принимает запросы на учётную запись: создаёт её с логином и временным паролем, включает, блокирует при увольнении, возвращает идентификатор учётной записи |
| S-03 | OpenTelemetry Collector | OTLP (транспорт - вопрос 8) | Принимает трассы, метрики, журналы |
| S-04 | Infra: GitHub Actions, Kubernetes, задание изменений схемы | Сборка образов по `reference-manager/**`, Job изменений схемы перед Deployment, readiness и liveness по служебным точкам, сетевая политика egress; realm, служебный клиент и права в Keycloak | Развёртывает сервис и его хранилище, настраивает доступ сервиса к Keycloak |

## 3. Кто чем владеет

| Актор | Создаёт | Читает | Изменяет, удаляет, восстанавливает | Добавляет справочники |
| --- | --- | --- | --- | --- |
| H-01 Администратор | записи классификаторов | классификаторы и кадровые справочники с историей, кроме окладов и отсутствий | записи классификаторов | нет, через H-04 |
| H-02 Читатель | - | классификаторы и кадровые справочники с историей, выгрузки, кроме окладов и отсутствий | - | - |
| H-04 Инженер | хранилище, методы, спецификацию | всё, что доступно H-01 | код и схему | да, новой версией сервиса |
| H-05 HR-администратор | HR-профили, подразделения, должности, назначения, оклады, отсутствия | всё, включая оклады и отсутствия | кадровые записи; увольняет сотрудников | нет |
| S-01 Потребители | - | записи и историю по своей роли | - | - |
| S-02 Keycloak | учётные записи по запросу сервиса | - | учётные записи по запросу сервиса | - |

Матрица прав по операциям API - в [070](070.role-matrix.md).
