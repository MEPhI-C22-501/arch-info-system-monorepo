# 080 - User Stories: читатель

> Формат - см. [состав документов](documents-composition.md), документ 080.

Актор [H-02](030.actors.md), роль [R-01](070.role-matrix.md). Читатель работает через интерфейс своей подсистемы или запрашивает выгрузку. Ему доступны общие классификаторы и кадровые справочники, кроме окладов и отсутствий. Формат и обозначения - как в [историях администратора](080.admin-user-stories.md).

## US-RD-01 - Выбрать значение справочника

Как читатель, я хочу видеть в форме своей подсистемы только действующие значения справочника, чтобы не выбрать удалённое.

**Связи:** UC-08; FR-RM-08, FR-RM-11.

- **AC-1. Given** в `currencies` есть записи ACTIVE и DELETED; **When** подсистема вызывает `List`; **Then** в ответе только ACTIVE, `total_size` равен их числу.
- **AC-2. Given** документ подсистемы ссылается на удалённую валюту; **When** подсистема читает её `Get`; **Then** запись возвращается со `state: DELETED`, документ отображается корректно.
- **AC-3. Given** справочник содержит 1 200 записей; **When** запрашиваю `page_size=200` и `order_by="display_name"` с `page_token` третьей страницы; **Then** получаю 200 записей с 401-й по 600-ю в порядке наименований и `total_size` 1 200.

## US-RD-02 - Найти запись по фильтру

Как читатель, я хочу отбирать записи выражением по полям, чтобы быстро найти нужное значение.

**Связи:** UC-08; FR-RM-08.

- **AC-1. Given** есть запись `currencies/EUR`; **When** вызываю `List` с `filter="name = \"currencies/EUR\""`; **Then** получаю ровно одну запись, `total_size` 1.
- **AC-2. Given** есть записи `Euro` и `Eurozone unit`; **When** вызываю `List` с `filter="display_name:\"Euro\""`; **Then** получаю обе.
- **AC-3. Given** справочник `currencies` имеет поле `minor_units`; **When** вызываю `List` с `filter="minor_units = 0 AND state = ACTIVE"`; **Then** получаю только активные валюты без дробной части.
- **AC-4. Given** фильтр ссылается на неизвестное поле; **When** вызываю `List`; **Then** получаю INVALID_ARGUMENT, а не пустой список.

## US-RD-03 - Выгрузить справочник в Excel

Как читатель, я хочу выгрузить отобранные записи в `.xlsx`, чтобы работать со справочником вне системы.

**Связи:** UC-09; FR-RM-40, FR-RM-41, FR-RM-42, NFR-RM-44, NFR-RM-45.

- **AC-1. Given** отобрал записи фильтром и сортировкой; **When** вызываю `List` с заголовком `Accept` для `.xlsx`; **Then** получаю файл, в котором строки соответствуют всему отбору, а не одной странице, в том же порядке.
- **AC-2. Given** файл получен; **When** открываю его в Excel; **Then** первая строка - имена полей, есть имя, наименование, состояние и поля справочника; предупреждений о повреждении нет; `numeric_code` `036` сохранён как текст.
- **AC-3. Given** запросил выгрузку с `show_deleted`; **When** файл открыт; **Then** удалённые записи присутствуют со `state: DELETED` и `delete_time`.

## US-RD-04 - Получить понятный отказ при слишком большой выгрузке

Как читатель, я хочу при превышении предела выгрузки получить понятный ответ, чтобы сузить отбор и повторить.

**Связи:** UC-09; FR-RM-43, NFR-RM-42.

- **AC-1. Given** предел выгрузки 50 000 записей и отбор даёт 60 000; **When** запрашиваю `.xlsx`; **Then** получаю FAILED_PRECONDITION с указанием предела; файл не формируется.
- **AC-2. Given** тот же отбор; **When** запрашиваю обычную страницу JSON; **Then** получаю страницу: предел относится только к выгрузке.

## US-RD-05 - Посмотреть историю значения

Как читатель, я хочу видеть, когда и кем изменилось значение справочника, чтобы объяснить расхождения в своих документах.

**Связи:** UC-15; FR-RM-46, FR-RM-47.

- **AC-1. Given** значение валюты переименовано неделю назад; **When** читаю `revisions` записи; **Then** вижу ревизию UPDATED с датой, автором и изменением `display_name` с прежним и новым значением.
- **AC-2. Given** документ создан при первой ревизии записи; **When** запрашиваю запись в состоянии на ревизию 1; **Then** получаю запись такой, какой она была при создании документа.
- **AC-3. Given** роль `reference-reader`; **When** читаю историю записи классификатора или кадрового справочника; **Then** получаю ответ.
- **AC-4. Given** роль `reference-reader`; **When** читаю `salaries` или `absences` либо их историю; **Then** получаю PERMISSION_DENIED.
