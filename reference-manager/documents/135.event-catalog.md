# 135 - Event Catalog

> Формат - см. [состав документов](documents-composition.md), документ 135.
> Источник - [системные требования, INT-RM-04, INT-RM-05](system-requirements.md#5-требования-к-интеграциям), [конституция, принцип I](../.specify/memory/constitution.md), [Event Storming](040.event-storming.md), [162](162.integration-solution.md).

## 1. Решение

Решение согласовано: события не публикуются и не потребляются. Потребители перечитывают данные по REST API. Целевой интервал перечитывания - не реже раза в час, потребитель может перечитывать чаще.

Решение принято командой 2026-09-14 (ADR-003, INT-RM-05). Очередь событий - один из видов интеграции в проекте, поэтому отказ от неё проверен по документам каждого потребителя: все они описывают обмен со справочниками как чтение по REST.

| Потребитель | Что записано в его документах | Документ | Редакция документа |
| --- | --- | --- | --- |
| Planning System | "события НСИ не предполагаются". Базовый обмен справочниками - REST, событие не является обязательным входом расчёта. Сервису нельзя требовать обязательную подписку Kafka | [030, S-02](../../planning-system/docs/030.actors.md), [020, D-02](../../planning-system/docs/020.system-context.md), [070](../../planning-system/docs/070.role-matrix.md) | 2026-09-22, 2026-09-24 |
| Task Tracker | Исходящий REST, периодический опрос и ручной запуск, кэш на своей стороне | [160](../../task-tracker/docs/block-i-integration-and-deployment/160.integration-plan.md), [020](../../task-tracker/docs/block-a-context-and-scope/020.system-context.md) | 2026-09-24 |
| QA System | REST с кэшем, чтение | [vision, раздел 8](../../qa/docs/vision.md) | 2026-09-28 |
| Reports | REST с кэшированием на стороне отчётов | [vision, раздел 8](../../reports/docs/vision.md) | 2026-09-21 |

Проверка выполнена 2026-10-02. Отдельного протокола согласования нет: подтверждением служат перечисленные редакции документов команд. Обоснование выбора REST против событий с вариантами и оценкой - в [162, раздел 2](162.integration-solution.md).

## 5. Внутренние факты

Доменные события из [040](040.event-storming.md) (ЗаписьСоздана, СотрудникУволен и другие) существуют как ревизии в истории справочника и как счётчики телеметрии (NFR-RM-27). В шину сообщений они не попадают.

## 6. Условие пересмотра

Решение пересматривается, если потребителю понадобится узнавать об изменении быстрее целевого интервала перечитывания, например о блокировке уволенного сотрудника в своём кэше. Такая потребность сейчас записана только как открытый вопрос 3 требований об инкрементальной выдаче. Пересмотр оформляется поправкой конституции (принцип I) и новым ADR. Заготовка формата события на этот случай приведена в [140, раздел 3](140.event-schema.md).
