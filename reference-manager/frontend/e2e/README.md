# Браузерные тесты админ-панели

Тесты на Playwright проходят экраны панели в браузере на работающем стенде: вход через Keycloak, список справочников, таблицу с фильтром и пустым отбором, форму с ошибкой у поля, роли `reader` и `outsider`, срез на момент и выгрузку отбора, групповую операцию подразделения, узкий экран, клавиатуру и тёмную тему. Сценарии совпадают с P-01, P-02, P-05 и P-11..P-14 [документа 115](../../documents/115.live-prototype.md).

Тесты меняют данные стенда (создают должность с уникальным кодом), поэтому идут в одном браузере по очереди. В CI они не запускаются, как и интеграционные тесты сервиса.

## Запуск

```bash
task up          # из reference-manager/, стенд с демонстрационными данными
task tests:e2e   # npm ci и npx playwright test в frontend/e2e
```

Браузер ставится командой `npx playwright install chromium` в этой папке. Вместо него можно указать Chromium, который уже есть на машине: `E2E_CHROMIUM=/путь/к/chrome task tests:e2e`. Другой стенд задаёт `E2E_BASE_URL` (по умолчанию `http://localhost:8084`).

После неудачного теста трасса лежит в `test-results/`, её открывает `npx playwright show-trace`.
