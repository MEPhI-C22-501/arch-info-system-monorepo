# 155 - Sequence-диаграммы

> Формат - см. [состав документов](documents-composition.md), документ 155.
> Источник - [Use Cases](060.use-cases.md), [контракты API](130.api-contracts.md), [логическая схема](146.logic-scheme.md).

Тайм-ауты: запрос ограничен таймаутом middleware (сейчас константа, K-07; для выгрузки требуется отдельный предел до 60 с по NFR-RM-43); запрос к хранилищу ограничен контекстом запроса; экспорт телеметрии не блокирует ответ.

## SD-01 Создание записи с проверкой полей

Use Case UC-03, UC-14; истории US-AD-01, US-AD-02.

```mermaid
sequenceDiagram
    participant A as Администратор
    participant H as Маршрутизация
    participant S as Сервис записей
    participant R as Хранилище
    A->>H: POST /v1/currencies?currency_id=PLN {display_name, numeric_code, minor_units}
    H->>H: разбор запроса, X-Request-Id, спан
    H->>S: Create(currencies, PLN, поля, актор)
    S->>S: проверка полей по схеме справочника
    alt поля неверны
        S-->>H: INVALID_ARGUMENT{fieldViolations}
        H-->>A: 400 google.rpc.Status
    else поля верны
        S->>R: BEGIN
        S->>R: вставить запись currencies/PLN, etag
        alt идентификатор занят
            R-->>S: нарушение уникальности
            S->>R: ROLLBACK
            H-->>A: 409 ALREADY_EXISTS
        else сохранено
            S->>R: вставить ревизию 1 CREATED {changes}
            S->>R: COMMIT
            H-->>A: 201 запись с name, state, etag
        end
    end
```

## SD-02 Удаление и восстановление

Use Case UC-05, UC-06; истории US-AD-04, US-AD-05.

```mermaid
sequenceDiagram
    participant A as Администратор
    participant H as Маршрутизация
    participant S as Сервис записей
    participant R as Хранилище
    A->>H: DELETE /v1/currencies/PLN (срез 2: etag)
    H->>S: Delete(currencies, PLN, актор, etag)
    S->>R: BEGIN
    S->>R: обновить delete_time, etag при условии state = ACTIVE [и etag = ожидаемый]
    alt 0 строк
        S->>R: прочитать запись
        alt записи нет
            H-->>A: 404 NOT_FOUND
        else уже удалена
            H-->>A: 400 FAILED_PRECONDITION
        else etag не совпал (срез 2)
            H-->>A: 409 ABORTED
        end
        S->>R: ROLLBACK
    else 1 строка
        S->>R: вставить ревизию DELETED {state, delete_time}
        S->>R: COMMIT
        H-->>A: 200 запись state = DELETED
    end
    A->>H: POST /v1/currencies/PLN:undelete
    H->>S: Undelete(currencies, PLN, актор)
    S->>R: обновить delete_time = null, etag при условии state = DELETED
    alt 0 строк
        H-->>A: 404 или 400 FAILED_PRECONDITION
    else 1 строка
        S->>R: вставить ревизию UNDELETED
        H-->>A: 200 запись state = ACTIVE
    end
```

## SD-03 Список с фильтром и выгрузка

Use Case UC-08, UC-09; истории US-RD-01..04.

```mermaid
sequenceDiagram
    participant C as Подсистема или читатель
    participant H as Маршрутизация
    participant S as Сервис записей
    participant F as Разбор filter
    participant X as Формирователь .xlsx
    participant R as Хранилище
    C->>H: GET /v1/currencies?filter=state = ACTIVE AND display_name:"e"&order_by=display_name&page_size=50
    H->>S: List(currencies, параметры)
    S->>F: разобрать filter и order_by по полям справочника
    alt неизвестное поле
        H-->>C: 400 INVALID_ARGUMENT
    else выражение верно
        S->>R: выборка страницы и total_size
        R-->>S: записи, total
        H-->>C: 200 {currencies[], next_page_token, total_size}
    end
    C->>H: тот же запрос, Accept: .xlsx
    H->>S: Export(currencies, параметры)
    S->>R: total_size отбора
    alt total > предел выгрузки
        H-->>C: 400 FAILED_PRECONDITION EXPORT_TOO_LARGE
    else в пределах
        S->>X: открыть файл с заголовками
        loop порции по 1000 записей
            S->>R: очередная порция отбора
            R-->>S: записи
            S->>X: добавить строки, идентификаторы как текст
        end
        X-->>S: файл
        H-->>C: 200 Content-Disposition attachment
    end
```

Соединение с хранилищем возвращается в пул между порциями; при превышении предела времени формирование прерывается ответом UNAVAILABLE (NFR-RM-43).

## SD-04 Запрос с токеном Keycloak (срез 2)

Use Case UC-10; история US-CS-02.

```mermaid
sequenceDiagram
    participant C as Сервис-потребитель
    participant KC as Keycloak
    participant M as Проверка токена
    participant J as Кэш ключей
    participant S as Сервис записей
    C->>KC: client credentials
    KC-->>C: access token (роль reference-reader)
    C->>M: GET /v1/currencies/EUR Authorization: Bearer
    M->>J: ключ по kid
    alt ключ в кэше
        J-->>M: ключ
    else нет ключа
        J->>KC: JWKS
        KC-->>J: ключи
        J-->>M: ключ
    end
    M->>M: подпись, издатель, получатель, срок
    alt токен недействителен
        M-->>C: 401 UNAUTHENTICATED
    else действителен
        M->>S: запрос с актором и ролями
        S->>S: роль имеет уровень операции? (reader: R X; admin: C R U X D)
        alt нет
            S-->>C: 403 PERMISSION_DENIED
        else да
            S-->>C: 200 запись
        end
    end
```

Ошибка загрузки ключей при пустом кэше даёт UNAVAILABLE на защищённых путях; ключи обновляются не чаще раза в минуту. Источник ключей может быть заменён конфигурацией (вопрос 7).

## SD-05 Развёртывание: задание изменений схемы и готовность

Use Case UC-12, UC-02; требования NFR-RM-21, FR-RM-31.

```mermaid
sequenceDiagram
    participant CI as CI/CD
    participant K as Kubernetes
    participant J as Задание изменений схемы
    participant DB as Хранилище
    participant P as Экземпляр reference-manager
    CI->>K: новый образ, манифесты
    K->>J: запустить задание
    J->>DB: применить изменения схемы, версия = N
    alt не применилось
        J-->>K: ошибка
        K-->>CI: развёртывание остановлено
    else применено
        J-->>K: успех
        K->>P: запустить Deployment
        K->>P: GET /ready
        P->>DB: доступность; версия схемы
        alt недоступно или версия < N
            P-->>K: 503 с перечнем проверок
            K->>K: трафик не подаётся, повтор
        else готов
            P-->>K: 200
            K->>K: трафик на экземпляр, старые экземпляры останавливаются
        end
    end
```

## SD-06 Реализация справочника

Use Case UC-02; история US-AD-06. Взаимодействие людей и репозитория, не сетевых компонентов.

```mermaid
sequenceDiagram
    participant T as Команда-потребитель
    participant E as Инженер справочников
    participant GH as Репозиторий и CI
    participant K as Развёртывание
    participant A as Администратор
    E->>T: уточнение полей и начальных данных справочника из состава первой версии
    T-->>E: поля, ограничения, данные
    E->>GH: изменение: схема записи в спецификации, хранилище, методы, тесты
    GH->>GH: линтер, тесты, сравнение спецификаций
    E->>GH: ревью CODEOWNERS, слияние
    GH->>K: новая версия, SD-05
    A->>K: наполнение записями (Create)
    T->>K: чтение по API
```

## SD-07 Чтение истории записи

Use Case UC-15; истории US-AD-08, US-RD-05, US-CS-06.

```mermaid
sequenceDiagram
    participant C as Читатель или подсистема
    participant H as Маршрутизация
    participant S as Сервис записей
    participant R as Хранилище
    C->>H: GET /v1/currencies/PLN/revisions?page_size=50
    H->>S: ListRevisions(currencies, PLN, страница)
    S->>R: запись существует?
    alt записи нет
        H-->>C: 404 NOT_FOUND
    else есть
        S->>R: ревизии PLN от новой к старой, total
        R-->>S: ревизии
        H-->>C: 200 {revisions[], next_page_token, total_size}
    end
    C->>H: GET /v1/currencies/PLN?revision=2
    H->>S: GetAtRevision(currencies, PLN, 2)
    S->>R: ревизии 1..2
    alt ревизии нет
        H-->>C: 404 NOT_FOUND
    else есть
        S->>S: применить changes ревизий 1..2 к пустой записи
        H-->>C: 200 CurrencyRecord на ревизию 2
    end
```
