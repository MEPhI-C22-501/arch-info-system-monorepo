# 140 - Схемы событий Reference Manager

**Блок G.** Редакция 1.0 от 2026-09-25, к ревью команды.
Основания: [135 Каталог событий](135.event-catalog.md).

## 1. Состояние

Схем событий нет: сервис не публикует и не потребляет события (INT-RM-05, BR-RM-09). Партицирование, версионирование схем и правила совместимости не определяются.

## 2. Что заменяет события для потребителей

| Потребность | Механизм | Где описан |
| --- | --- | --- |
| Узнать актуальное значение | `GET /{catalog}/{id}` или `GET /{catalog}?code=` | [130](130.api-contracts.md) |
| Обновить локальную копию | Периодическое перечитывание `GET /{catalog}` с `include_deleted=true` и сравнение `version` | [US-CS-05](../block-c-requirements-and-roles/080.consumer-service-user-stories.md) |
| Сослаться на изменение | `version`, `updated_at`, `updated_by` записи | [050](../block-b-domain-analysis/050.entities.md) |

## 3. Условие пересмотра

Документ заполняется только после решения вопроса 3 требований и поправки конституции. Формат конверта при этом наследует поля записи: `id`, `code`, `version`, `updated_at`, состояние; ключ партиции - `id` записи.
