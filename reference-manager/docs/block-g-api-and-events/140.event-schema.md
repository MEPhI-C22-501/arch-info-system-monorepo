# 140 - Event Schema

> Формат - см. [состав документов](../../../task-tracker/docs/documents-composition.md), документ 140.
> Источник - [135 - Каталог событий](135.event-catalog.md).

## 1. Состояние

Схем событий нет: сервис не публикует и не потребляет события (INT-RM-05, BR-RM-09). Партицирование, версионирование схем и правила совместимости не определяются.

## 2. Что заменяет события для потребителей

| Потребность | Механизм | Где описан |
| --- | --- | --- |
| Узнать актуальное значение | `Get` по имени записи | [130](130.api-contracts.md) |
| Обновить локальную копию | Периодический `List` с `show_deleted` | [US-CS-05](../block-c-requirements-and-roles/080.consumer-service-user-stories.md) |
| Узнать, что и когда изменилось | `ListRevisions` записи | [US-CS-06](../block-c-requirements-and-roles/080.consumer-service-user-stories.md) |

## 3. Условие пересмотра

Документ заполняется только после решения вопроса 3 требований и поправки конституции. Формат события при этом наследует поля ревизии: имя записи, действие, время, изменения; ключ партиции - имя записи.
