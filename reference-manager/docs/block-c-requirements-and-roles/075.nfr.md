# 075 - Нефункциональные требования Reference Manager

**Блок C.** Редакция 1.0 от 2026-09-25, к ревью команды.
Основания: [Системные требования, раздел 10](../system-requirements.md#10-нефункциональные-требования), [конституция](../../.specify/memory/constitution.md), [ADR](../block-h-architecture-and-logic/145.architecture-decisions.md).

Идентификаторы NFR-RM-NN взяты из системных требований без изменений. Ниже добавлены измеримая метрика, порог, способ проверки и связь с решениями. Пороги, помеченные "предложено", ждут подтверждения Infra (вопрос 9 требований).

## 1. Производительность

| ID | Требование | Метрика | Порог | Проверка | ADR |
| --- | --- | --- | --- | --- | --- |
| NFR-RM-18 | Время отклика | p95 латентности `GET /{catalog}` и `GET /{catalog}/{id}` при 100 запросах в секунду; p95 операций записи | чтение <= 100 мс, запись <= 300 мс, предложено | Нагрузочный тест на стенде против образцовых справочников, T-NFR-18 | ADR-001 |
| NFR-RM-20 | Полнота списков и индексы | Наличие `total` в ответе; план запроса списка и чтения по `code` использует индекс | 100 процентов запросов списков; нет Seq Scan на таблицах свыше 1000 строк | Контрактный тест на `total`; `EXPLAIN` в интеграционных тестах, T-NFR-20 | ADR-001 |
| NFR-RM-43 | Время выгрузки | Длительность формирования файла предельного объёма; время удержания соединения с базой | <= 60 с; соединение возвращается в пул после чтения данных | Тест выгрузки 50 000 строк, T-NFR-43 | ADR-008 |
| NFR-RM-42 | Предел выгрузки | Число записей в одной выгрузке | <= 50 000, задаётся конфигурацией | Тест ответа 413 сверх предела, T-FR-43 | ADR-008 |
