## Результат каждой вехи

- **M4:** справочники первой версии заведены, для любого из них работают пять стандартных методов, Undelete и история с одинаковым поведением; записи проверяются по полям, читаются с фильтром и выгружаются в `.xlsx`; сервис проходит `/ready` и отдаёт телеметрию. Соответствует критериям приёмки 1-10 раздела 11 требований. API доступен только из внутренней сети.
- **M5:** API защищён токенами и ролями, администраторы работают через интерфейс.
- **После M5:** возможности E-09 по результатам согласования с потребителями.
