# 070 - RBAC (Role-Based Access Control)

> Формат - см. [состав документов](documents-composition.md), документ 070.
> Источник - [системные требования, разделы 3 и 4.5](system-requirements.md), [акторы](030.actors.md), [конституция, принцип VII](../.specify/memory/constitution.md).

Мультиарендности нет: права роли действуют на все справочники и все записи (BR-RM-13).

## 1. Уровни доступа

| Уровень | Обозначение | Методы |
| --- | --- | --- |
| create | C | `Create` |
| read | R | `List`, `Get`, чтение истории и состояния на ревизию |
| update | U | `Update`, `Undelete` |
| execute | X | Выгрузка `.xlsx` |
| delete | D | `Delete` (мягкое) |

## 2. Роли

| ID | Роль | Уровни | Где определена | Кому выдаётся | Акторы |
| --- | --- | --- | --- | --- | --- |
| R-00 | Внутренняя сеть без токена | C R U X D | Срез 1: аутентификации нет, сервис недоступен снаружи (NFR-RM-30) | Всем вызывающим внутри сети стенда | Все |
| R-01 | `reference-reader` | R X | Claim ролей токена Keycloak (FR-RM-22) | Всем пользователям ERP и сервисным учётным записям подсистем | H-02, S-01 |
| R-02 | `reference-admin` | C R U X D | Claim ролей токена Keycloak (FR-RM-22) | Участникам команды справочников | H-01 |
| R-03 | Инженер справочников | репозиторий, не API | CODEOWNERS | Участникам команды справочников | H-04 |

Роли редактора нет (2026-09-15). Путь к ролям в токене не согласован (вопрос 6 требований).

## 3. Матрица прав на операции API

Для каждого справочника, например `countries`.

| Операция | Уровень | R-00 срез 1 | R-01 reader | R-02 admin |
| --- | --- | --- | --- | --- |
| `POST /v1/countries` Create | C | да | нет, PERMISSION_DENIED | да |
| `GET /v1/countries` List, любые `filter`, `order_by`, `show_deleted` | R | да | да | да |
| `GET /v1/countries/{id}` Get, включая DELETED и состояние на ревизию | R | да | да | да |
| `GET /v1/countries/{id}/revisions` история | R | да | да | да |
| `GET /v1/countries` с `Accept` `.xlsx` выгрузка | X | да | да | да |
| `PATCH /v1/countries/{id}` Update | U | да | нет, PERMISSION_DENIED | да |
| `POST /v1/countries/{id}:undelete` Undelete | U | да | нет, PERMISSION_DENIED | да |
| `DELETE /v1/countries/{id}` Delete | D | да | нет, PERMISSION_DENIED | да |
| `/admin/` интерфейс администрирования | - | - | вход возможен, действия C U D скрыты и отклоняются сервером | да |
| `GET /health`, `GET /ready` | - | без токена | без токена | без токена |
| `GET /metrics` по флагу конфигурации | - | внутренняя сеть | внутренняя сеть | внутренняя сеть |
| Создание, изменение, удаление справочника через API | - | операции нет (FR-RM-38) | нет | нет |
| Изменение или удаление ревизий | - | операции нет (FR-RM-45) | нет | нет |

Права проверяются на сервере перед операцией по паре "роль - уровень" (FR-RM-23). Интерфейс скрывает недоступные действия, но сервер проверяет права независимо (FR-RM-28).

## 4. Права на уровне репозитория и инфраструктуры

| Действие | R-03 Инженер | Infra |
| --- | --- | --- |
| Реализовать справочник из состава первой версии: хранилище, методы, спецификация, тесты | да, через pull request с ревью CODEOWNERS | - |
| Применить изменения схемы хранилища | нет, только через задание | да |
| Изменить конфигурацию окружения, секреты | нет | да |
| Прямой доступ к хранилищу | нет, кроме задания изменений схемы | нет |

## 5. Права учётных записей в хранилище

| Объект | Чтение | Добавление | Изменение | Удаление | Схема |
| --- | --- | --- | --- | --- | --- |
| Записи справочников (учётная запись сервиса) | да | да | да | нет (NFR-RM-16) | нет |
| История справочников (учётная запись сервиса) | да | да | нет | нет | нет |
| Учётная запись задания изменений схемы | да | да | да | да | да |

## 6. Соответствие акторов и ролей

| Актор | Роль | Уровни | Обоснование |
| --- | --- | --- | --- |
| H-01 Администратор справочников | R-02 | C R U X D | Ведёт записи всех справочников |
| H-02 Читатель | R-01 | R X | Читает, смотрит историю, выгружает |
| H-04 Инженер | R-03 и R-02 | репозиторий; C R U X D | Меняет код и схему, в API действует как администратор |
| S-01 Сервисы-потребители | R-01 по client credentials | R X | Только чтение |
| S-04 Infra | без роли API | - | Служебные точки не требуют токена |
