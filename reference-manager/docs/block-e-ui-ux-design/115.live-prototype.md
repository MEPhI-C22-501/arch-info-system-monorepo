# 115 - Интерактивный прототип интерфейса Reference Manager

**Блок E.** Редакция 1.0 от 2026-09-25, к ревью команды.
Основания: [110 UI/UX](110.ui-ux.md), [Системные требования, раздел 8](../system-requirements.md#8-требования-к-интерфейсу).

## 1. Состояние

Прототипа пока нет. Интерфейс относится к срезу 3, стек фронтенда не выбран (вопрос стека - ADR до начала среза). Документ фиксирует, что и где будет создано, чтобы прототип появился раньше кода интерфейса.

## 2. Что будет в прототипе

- Один файл `reference-manager/ui/prototype/index.html` со встроенными стилями и данными; переключение экранов внутри файла без сборки, по образцу прототипа Task Tracker (`task-tracker/frontend/prototype/index.html`).
- Экраны из [110](110.ui-ux.md): S-01 список справочников, S-02 таблица записей `currencies` и `countries`, S-03 форма записи, S-04 отказ в доступе.
- Данные прототипа - образцовые справочники валют и стран с несколькими удалёнными записями, чтобы показать флаг "показывать удалённые" и состояние DELETED в форме.
- Показанные состояния: пустая таблица, ошибка 422 по полям в форме, баннер 409 при занятом коде, подтверждение удаления, сообщение 413 при выгрузке.

## 3. Сценарии для проверки на прототипе

| № | Сценарий | Проверяемое | Истории |
| --- | --- | --- | --- |
| P-01 | Открыть список, перейти в `countries`, найти по `q`, отсортировать по названию | Понятность фильтров и таблицы | US-RD-01, US-RD-02 |
| P-02 | Создать запись с ошибкой в ссылочном поле, исправить, сохранить | Ошибки у полей, выбор из другого справочника | US-AD-01, US-AD-02 |
| P-03 | Удалить запись, включить показ удалённых, вернуть в работу | Подтверждения, состояние, версия | US-AD-04, US-AD-05 |
| P-04 | Выгрузить отбор, получить 413, сузить отбор | Понятность отказа | US-RD-03, US-RD-04 |
| P-05 | Войти с ролью reader | Скрытие действий записи | US-AD-07, 070 |

## 4. Критерий готовности

Прототип принят, когда администратор из команды справочников проходит сценарии P-01..P-05 без подсказок, а замечания перенесены в [110](110.ui-ux.md). Только после этого выбирается стек и начинается срез 3.
