# 130 — API Contracts

> Формат — см. [состав документов](documents-composition.md), документ 130.
> Спецификация — [`../api/openapi/v1/openapi.yaml`](../api/openapi/v1/openapi.yaml). Сценарии — [060](060.use-cases.md), права — [070](070.role-matrix.md), последовательности — [155](155.sequence-diagrams.md).

## 1. Общие правила

| Правило | Значение |
| --- | --- |
| Базовый путь | `/api/v1`; несовместимое изменение — `/api/v2` |
| Версия контракта | `0.1.0-draft` по semver; статус `draft` снимается после согласования Q-REP-04 и Q-REP-05 |
| Аутентификация | `Authorization: Bearer <JWT>` от Keycloak; проверяются подпись по JWKS, `iss`, `aud = reports`, срок |
| Авторизация | Роль из [070](070.role-matrix.md) и область данных пользователя; на сервере |
| Формат | JSON, UTF-8; даты — ISO 8601, часовой пояс в ответе; часы — число с двумя знаками |
| Пагинация | `page` с 1, `pageSize` до 200; в ответе `total` |
| Корреляция | Заголовок `X-Correlation-Id` принимается или создаётся, возвращается в ответе и пишется в журнал |
| Только чтение источников | API Reports не изменяет данных источников ни в одном методе (FR-CALC-08) |

## 2. Единый формат ошибки

`application/problem+json`:

```json
{
  "type": "https://reports.arch.local/errors/invalid-parameter",
  "title": "Недопустимый параметр",
  "status": 422,
  "code": "INVALID_PARAMETER",
  "detail": "Период не может быть длиннее 366 дней",
  "errors": [{ "field": "params.periodTo", "message": "Период не может быть длиннее 366 дней" }],
  "correlationId": "7f1c2b9a-3e44-4b7e-9a51-0c2d8e1f4a10"
}
```

| HTTP | `code` | Когда |
| --- | --- | --- |
| 400 | `MALFORMED_REQUEST` | Тело не разбирается |
| 401 | `UNAUTHENTICATED` | Нет токена или токен недействителен |
| 403 | `FORBIDDEN` | Нет роли или объект вне области данных; объект в сообщении не раскрывается |
| 404 | `NOT_FOUND` | Нет объекта или он чужой (представление, выгрузка, подписка) |
| 409 | `CONFLICT` | Загрузка потока уже идёт; изменение подписки по устаревшей версии |
| 410 | `GONE` | Срок хранения файла выгрузки истёк |
| 422 | `INVALID_PARAMETER` | Параметр отчёта недопустим |
| 422 | `RESULT_TOO_LARGE` | Результат больше предела интерактивного отчёта; в `detail` — предложение выгрузки |
| 503 | `SOURCE_NOT_LOADED` | Источник отчёта ни разу не загружался (`UNKNOWN`) |

## 4. Примеры

**Успешный запрос отчёта.** `POST /api/v1/reports/R-01/query`

```json
{
  "params": { "periodFrom": "2026-09-29", "periodTo": "2026-10-03", "projectIds": ["6b0f3f0e-2c1d-4c55-9a7e-1d2f3a4b5c6d"] },
  "slice": ["employee"],
  "compareWithPrevious": false
}
```

Ответ `200`:

```json
{
  "reportId": "R-01",
  "reportVersion": 1,
  "generatedAt": "2026-10-05T12:04:11+03:00",
  "freshness": [
    { "source": "task-tracker", "stream": "time-logs", "dataAsOf": "2026-10-05T12:00:00+03:00", "state": "FRESH" }
  ],
  "columns": [
    { "key": "employee", "title": "Сотрудник", "type": "dimension" },
    { "key": "M-01", "title": "Факт, ч", "type": "measure", "formula": "Сумма часов записей трудозатрат за период" }
  ],
  "rows": [
    { "employee": { "id": "employees/1042", "label": "Иванова А." }, "M-01": 37.50 },
    { "employee": { "id": null, "label": "не задано" }, "M-01": 2.00 }
  ],
  "totals": { "M-01": 39.50 }
}
```

**Ошибка: результат слишком большой.** Ответ `422`:

```json
{
  "type": "https://reports.arch.local/errors/result-too-large",
  "title": "Результат слишком большой",
  "status": 422,
  "code": "RESULT_TOO_LARGE",
  "detail": "Отчёт содержит 48 210 строк при пределе 10 000. Сформируйте выгрузку: POST /api/v1/exports",
  "correlationId": "0a9d7c1e-55b2-4c18-8d0e-7b6a5f4e3d21"
}
```

**Асинхронная выгрузка.** `POST /api/v1/exports` с `{"reportId": "R-01", "params": {...}, "format": "xlsx"}` → `202` и `{"exportId": "…", "status": "QUEUED"}`; после готовности `GET /api/v1/exports/{exportId}` → `{"status": "COMPLETED", "expiresAt": "…"}`; файл — `GET /api/v1/exports/{exportId}/file`. Срок истёк — `410 GONE`.

## 5. Входящие контракты

Контракты принадлежат источникам; Reports их только использует. Изменения согласуются с владельцем до выпуска.

| Источник | Вызов | Отбор и пагинация | Что берём | Документ владельца |
| --- | --- | --- | --- | --- |
| Task Tracker | GET `/api/v1/reports/work-items`, `/reports/iterations`, `/reports/time-logs`, `/reports/statuses`, `/reports/history` | Период, проект, исполнитель; `page`, `pageSize` ≤ 500; единого snapshot нет | Задачи, итерации, трудозатраты, справочник статусов с категориями, история изменений | [130](../../task-tracker/docs/block-g-api-and-events/130.api-contracts.md), [OpenAPI](../../task-tracker/docs/block-g-api-and-events/openapi.yaml) |
| Planning System | GET `/api/v1/projects/{projectId}/projection` | — | Оперативная проекция плана и прогноза, `quality`, `dataAsOf` | [130](../../planning-system/docs/130.api-contracts.md), [OpenAPI](../../planning-system/docs/contracts/openapi.json) |
| Planning System | POST `/api/v1/exports`, GET `/api/v1/exports/{batchId}`, GET `/api/v1/exports/{batchId}/rows` | Область партии; страницы неизменяемой партии | План, потребность, доступность, назначения, прогноз; деньги при `cost.read` | То же |
| Reference Manager | GET `/v1/employees`, `/v1/org_units`, `/v1/positions` и справочники ролей и грейдов | `show_deleted=true`, `page_size` ≤ 200, `page_token` до пустого `next_page_token` | Сотрудники, подразделения, должности, проектные роли, грейды | [130](../../reference-manager/documents/130.api-contracts.md) |
| QA System | GET `/api/v1/reports/{resource}`: `test-plans`, `test-runs`, `test-results`, `defects` | `updatedSince`, `page`, `pageSize` | Тест-планы, прогоны, результаты, дефекты для первичной загрузки и сверки | [130](../../qa/docs/130.api-contracts.md), [OpenAPI](../../qa/api/openapi/v1/openapi.yaml) |

**Предложение Reports по полям партии Planning System (Q-REP-05).** Строка партии содержит: `rowType` (`PLAN_ITEM`, `DEMAND`, `ALLOCATION`, `AVAILABILITY`, `FORECAST`), `projectId`, `planVersionId`, `logicalItemId`, `employeeId`, `projectRoleCode`, `weekStart`, `date`, `hours`, `plannedStart`, `plannedFinish`, `isBaseline`, `forecastFinish`, `budgetHours`, `budgetAmount`, `currency`, `quality`, `dataAsOf`. Расписание — раз в час и по `PlanActivated`; срок хранения партии — не менее 7 суток.

**Тайм-ауты и повторы при вызове источников.** Соединение — 3 с, ответ — 10 с; до 3 повторов при сетевой ошибке, `429` и `5xx` с паузой 2, 4, 8 с; `4xx`, кроме `429`, не повторяются.
