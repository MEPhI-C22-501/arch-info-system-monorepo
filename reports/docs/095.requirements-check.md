# 095 — Traceability Matrix

> Формат — см. [состав документов](documents-composition.md), документ 095.
> Источник требований — [vision 0.3](vision.md) и [075](075.nfr.md). FR-OPS, FR-DWH, FR-OLAP, FR-DASH и NFR-15…20 добавлены в vision 0.3 по замечаниям от 01.10.2026; INT-01…13 введены в комплекте.

Статусы относятся к **полноте документации**, а не к реализации: кода Reports в репозитории ещё нет. **covered** — требование описано в документах и связано с историей и проверкой; **partial** — описано, но зависит от несогласованной договорённости Q-REP; **missing** — не покрыто.

## 5. Проверки

Проверки T-01…T-35 — unit- и E2E-тесты, которые пишутся на этапе 5. Каждая проверка формул (T-12…T-17) выполняется на эталонном наборе: 3 проекта, 2 итерации, 40 задач, 300 записей трудозатрат, 2 прогона, 15 дефектов с переоткрытием. Ожидаемые значения рассчитываются вручную и хранятся рядом с тестом. E2E-проверка потока: источник (заглушка по OpenAPI источника) → ETL → DWH → отчёт API → ожидаемое значение.
