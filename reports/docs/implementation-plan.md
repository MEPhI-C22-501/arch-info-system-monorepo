Состояние на 2026-10-24. Целевая архитектура — [145](145.architecture-decisions.md),
[150](150.component-diagram.md), [165](165.deployment-diagram.md).
Код и команды запуска — [pilots](../pilots/README.md).

| Часть | Реализовано | Проверка и ограничение |
| --- | --- | --- |
| Контракты источников | QA: пять ресурсов; HR: allowDeleted/pageSize/pageToken, числовые ID; Planning: manifest 1.0.0 и cursor; Tracker: отчётные страницы | Сверены с файлами владельцев. Это не подтверждение общего доступа |
| P-01 ETL | Пять ресурсов Tracker, проверка OpenAPI, staging, атомарный merge, журнал, checkpoint; блокировка конкурирующих загрузок | Проверены SQLite и отдельный PostgreSQL 16.2; полный скан без гарантии общего snapshot источника; локальный планировщик раз в 60 секунд |
| Адаптеры Planning/QA/HR | Проверка партий/страниц, исходные записи в dwh.source_record | Наблюдаемая история SCD2 справочников с закрытием версий и явными tombstone; цельные суточные снимки. Типизированная звезда и локальный событийный конвейер реализованы; историческая догрузка требует доступной истории источника |
| API R-01 | Только чтение, период, группировки, пагинация, dataAsOf/freshness, livez/readyz, JWT/JWKS, роли admin/member, серверный фильтр | Проверен HTTP с динамическими тестовыми ключами; app.subject_binding обязателен для участника; расширенный /api/v1 описан в product-implementation.md; ETL admin/embedding endpoints остаются |
| P-02 Superset | Bootstrap R-01, OIDC Keycloak, роль Gamma, RLS, SQL API Cube | Подтверждены три входа и дашборд в браузере; 3,75/7,50/11,25 часа, чужой фильтр и SQL Lab; без роли вход отклонён; отзыв/возврат роли проверен, сеанс ограничен exp токена |
| P-03 Cube | Семейства M-01…M-20, M-16 остаётся неутверждённым, JWT и области доступа | Нативный прогон: миллион строк, 20 клиентов, 100 запросов, p95 0,0180 с, предагрегация, детализация и сортированный SQL; BI проверен в контейнерах, общий стенд отдельно |
| Локальный запуск | Compose, отдельные роли БД, детерминированные демоданные, загрузка секретов только из ~/secrets.env | Docker/Compose и Colima установлены; PostgreSQL → ETL → Cube → Superset + Keycloak запущены локально; очередь memory, без Cubestore |
| R-02…R-11, файлы, подписки, аудит | Реализованы API и UI, CSV/XLSX/печать, owned objects, текущие роли Keycloak при доставке, append-only audit | [Объём и пределы](product-implementation.md); реальные источники и нагрузка отдельно |
| Проверки и CI | Эталон 3 проекта/40 задач/300 time logs, четыре HTTP-источника → PostgreSQL → API; восстановление pg_dump; сканер секретов; шаблон unit/E2E- и BI-job | [Покрытие T-01…T-35](test-evidence.md); GitHub workflow не зарегистрирован: .github/workflows находится за пределами reports/ |

Подробные результаты — [проверка безопасности](security-check.md) и
[артефакты проверок](../pilots/artifacts/verification.json). Ни один локальный
passed не закрывает Q-REP без ответа второй стороны. Разбор исходных замечаний,
границы локальной приёмки и оставшаяся разработка — [реестр](review-status.md).

Запрос Planning System по партии опубликован в
[задаче согласования](https://github.com/MEPhI-C22-501/arch-info-system-monorepo/issues/147).
Ветка Infra `infra-local-stand` уже содержит проект primary/read-replica и ADR-012; ресурс в общем `main` и решение преподавателя пока не подтверждены.

Подготовленные в Reports предложения не являются ответом, отправленным в GitHub,
и не объявляются принятыми владельцами. Предложение ежедневной загрузки
Planning не обеспечивает NFR-15 ≤ 1 часа; расхождение требует явного решения.

## 3. Следующая итерация

Оценки и даты — предложение для распределения внутри команды. Ответственные
даны ролями; персональное назначение и дата защиты требуют решения команды.

| Задача | Ответственный | Оценка | Срок | Критерий готовности / зависимость |
| --- | --- | --- | --- | --- |
| Повторить BI на общем стенде, согласовать немедленный отзыв | Разработчик BI / Infra | 6 ч | 2026-10-28 | Локальный прогон и скриншоты готовы; остаются общие Keycloak/ID mapping, Cubestore, back-channel logout; локальные отзыв нового входа, exp и ротация ключей проверены |
| Повторить Cube и нагрузку на общем стенде | Разработчик BI | 6 ч | 2026-10-29 | Миллион строк, 20 клиентов, p95 и реальная предагрегация, без ослабления фильтра |
| Получить решения Q-REP-01/11/15/16 | Архитектор | 4 ч работы + ожидание | 2026-11-02 | Датированные ответы, состав ресурса и ID mapping |
| Подключить реальные Tracker и HR | Разработчик ETL | 12 ч | 2026-11-02 | Минимальные роли, SCD2, удаления, сверка ID/числа, безопасная область |
| Подключить реальные партии Planning и QA | Разработчик ETL | 12 ч | 2026-11-06 | Manifest, cost.read, архивы, качество, восстановление и контроль свежести |
| Принять реализованную звезду и отчёты на реальных источниках | Разработчик Reports | Оценка после доступов | И-M3…И-M5 | Локальные R-01…R-11, файлы, подписки и аудит уже реализованы; нужны реальные контракты и объёмы |
| Подключить общую CI и среду | Разработчик / Infra | 4 ч | 2026-11-02 | Отдельно разрешённое изменение .github, успешный удалённый прогон |
| Общая проверка безопасности и восстановления | Команда Reports / Infra | 6 ч | До защиты | S-01…S-12, read-replica, резервная копия, реальные роли и интеграции |

Полная подсистема не считается законченной до реализации отчётов, потоков,
областей доступа и приёмки на общем окружении. Критерии не понижаются до уровня
локальных пилотов.
