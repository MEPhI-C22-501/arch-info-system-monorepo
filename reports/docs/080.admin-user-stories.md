# 080 — User Stories: администратор отчётности

> Формат — см. [состав документов](documents-composition.md), документ 080.
> Актор — [H-06](030.actors.md), роль — [RL-06](070.role-matrix.md).

## US-AD-01 — Проверить актуальность источников

Как администратор отчётности, я хочу видеть по каждому источнику время актуальности, последний пакет и последнюю сверку, чтобы быстро понять, почему отчёт устарел.

- **UC:** [UC-07](060.use-cases.md#uc-07-проверить-актуальность-данных-источника). **Эпик:** E-13.
- GWT-1: **Given** последний пакет Task Tracker завершился `FAILED` из-за `503`, **When** я открываю страницу актуальности, **Then** вижу поток в `STALE`, причину, время последнего успешного пакета и следующей попытки.
- GWT-2: **Given** ночная сверка нашла 3 недостающие записи и догрузила их, **When** я открываю журнал сверки, **Then** вижу `missing = 3`, `fixed = 3`, статус «завершена».

## US-AD-02 — Запустить загрузку вручную

Как администратор отчётности, я хочу запустить загрузку источника вне расписания, чтобы обновить данные после устранения сбоя.

- **UC:** [UC-07](060.use-cases.md#uc-07-проверить-актуальность-данных-источника). **Эпик:** E-13.
- GWT-1: **Given** источник снова доступен, **When** я запускаю загрузку Task Tracker, **Then** создаётся пакет, после `LOADED` поток переходит в `FRESH`.
- GWT-2: **Given** загрузка этого источника уже идёт, **When** я запускаю её ещё раз, **Then** получаю `409` и ссылку на текущий пакет.

## US-AD-03 — Настроить пределы выгрузок

Как администратор отчётности, я хочу задавать предел синхронной выгрузки и срок хранения файлов, чтобы управлять нагрузкой и объёмом бакета.

- **UC:** [UC-18](060.use-cases.md#uc-18-администрировать-каталог). **Эпик:** E-11.
- GWT-1: **Given** я установил срок хранения 3 дня, **When** проходит 3 дня после формирования, **Then** файл удалён из MinIO, задание `EXPIRED`.

## US-AD-04 — Не видеть лишнего

Как администратор отчётности, я не хочу по умолчанию видеть бизнес-данные отчётов, чтобы администрирование не давало доступа к трудозатратам сотрудников.

- **Эпик:** E-14.
- GWT-1: **Given** у меня только роль `reports-admin`, **When** я запрашиваю R-01, **Then** получаю `403`.
