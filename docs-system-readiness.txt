Закрыт 10 → выгрузка в хранилище работает на живых источниках: это отдельно

недостающем источнике (QA) и одном несогласованном формате (трекер).
Пока не закрыт разрыв 1, остальные закрывать бессмысленно: проверять негде.

ЧАСТЬ 4. ЕДИНЫЙ КРИТЕРИЙ ПРИЁМКИ (предлагается как обязательный)
--------------------------------------------------------------------------------
На машине, где нет ничего, кроме Docker:
  1. git clone репозитория в пустой каталог;
  2. одна команда подъёма всей системы из корня (сейчас там пусто);
  3. вход одним пользователем во все пять подсистем;
  4. сквозной сценарий: создать проект и план → утвердить → увидеть задачи в
     трекере → списать трудозатраты → создать тест-кейс и прогнать → получить
     дефект в трекере как «Ошибку» → увидеть план-факт в планировании и
     отчёт в отчётности;
  5. отрицательные проверки: нет роли — отказ, истёкший токен — отказ, чужой
     объект — отказ.
Пока этот сценарий не проходит целиком на живой среде, систему нельзя считать
работающей — независимо от того, сколько тестов проходит внутри каждого модуля.
