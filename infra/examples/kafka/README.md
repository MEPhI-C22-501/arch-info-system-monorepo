# Эталон Kafka

`worker.py` подтверждает offset после успеха или после записи в DLQ. Три попытки, паузы 0.2/0.4/0.8 с, без отдельного retry-топика.

`check.py` проверяет успех, дубль, падение после записи результата, исчерпание попыток, недоступный DLQ и сохранение исходного сообщения. Отдельно principal `qa` не может писать в `task-tracker.events.v1`.
