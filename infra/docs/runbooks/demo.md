# Демонстрация

Сквозной сценарий всех пяти модулей не собран: нет HR API, нет серверов Planning, Reports и QA. Ниже то, что показывает сам стенд, без подмены модулей моками.

1. Вход эталона: токен `example-caller` принимается, токен `example-stranger` отклоняется.
2. Кадровый профиль и связанная учётная запись справочников — блокер D-PROV, прямой вставки в их базу нет.
3. Проект и задача — в витрине лежат устойчивые ID `10000000-0000-4000-8000-000000000003` и `...0004`. Это фикстура, не запись Task Tracker.
4. Событие, повтор, падение до commit и DLQ — `infra/examples/kafka`.
5. Объект S3 и отказ чужого ключа — `infra/examples/s3`.
6. ETL с обрывом партии — `infra/examples/etl`.
7. Реплика витрины читает строку и отклоняет запись.

Команда прогона — `infra/scripts/smoke.sh`. Отчёт этого прогона дописывается после фактического запуска и не заполняется заранее.
