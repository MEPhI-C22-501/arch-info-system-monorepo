# Выпуск и откат

1. Проверки CI проходят на доверенной ветке.
2. Образы фиксируются digest в `infra/releases`.
3. Deploy workflow проверяет манифест и не ходит на внешний хост: площадка не выбрана.
4. Откат приложения — повторный запуск предыдущего digest, если схема данных совместима.
5. Откат схемы и уже записанных данных автоматически не выполняется. Для витрины Reports есть `infra/scripts/backup-restore.sh`: копия поднимается отдельным контейнером, это не офлайн-носитель.

Повторно собирать образ во время deploy не нужно.
