# 160. План интеграций инфраструктуры

Участники: инфраструктура и команды Task Tracker, Planning System, Reference Manager, Reports, QA. Срок в таблице — блокируемая веха команды, а не назначенная дата: даты и фамилии не выдуманы. Статус `proposed` означает предложение одной стороны. Молчание второй стороны не переводит пункт в `agreed`.

## 2. Матрица готовности модулей

| Модуль | Что есть в репозитории | Образ | В общем Compose | Статус поставки |
| --- | --- | --- | --- | --- |
| Task Tracker | код, Dockerfile, свой Compose и realm | собирается командой | `compose.modules.yaml`, не входит в базовый стенд | сервер есть, сквозной прогон с общей средой отдельно не закрыт |
| Reference Manager | сервис, OpenAPI health и currency, свой Compose | собирается командой | `compose.modules.yaml` | общего OpenAPI нет |
| Planning System | документы и предлагаемые контракты | нет | нет | blocked |
| Reports | документы, OpenAPI draft, прототип | нет | только БД витрины и реплика, которые ведёт Infra | blocked |
| QA | документы, OpenAPI draft | нет | бакет, клиенты и топики подготовлены | blocked |

Мок эталона не заменяет строку таблицы.

## 3. Порядок приёмки связи

1. Обе стороны называют владельца контракта и статус `draft` или `agreed`.
2. Инфраструктура создаёт доступ: клиент, бакет или топик и ACL.
3. Издатель и потребитель проходят пример на стенде.
4. Только после этого статус становится `verified`.

Эталон `dev.infra.examples.v1` принадлежит инфраструктуре и не является бизнес-контрактом Task Tracker.
