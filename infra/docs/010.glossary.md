# 010. Глоссарий

| Термин | Определение | Источник истины | Владелец данных |
| --- | --- | --- | --- |
| Core | Прежнее имя схемы «приложение + его БД». Отдельного сервиса и каталога в репозитории нет | [vision](../vision.md) | команда владеет своим приложением и своей базой |
| Realm | `arch-info-system` в Keycloak | Keycloak | инфраструктура владеет realm, справочники координируют профиль сотрудника |
| Provisioning | Синхронное создание учётной записи из справочников через Admin API | vision §3 | координация у Reference Manager, учётная запись у Keycloak |
| Web API | Синхронный REST/JSON по OpenAPI | спецификация команды | команда-издатель API |
| Событие | Сообщение Kafka at-least-once | каталог издателя | издатель |
| `eventId` | Идентификатор события для дедупликации. Написание `event_id` в старых текстах — то же понятие | [140](140.event-schema.md) | издатель события |
| S3-обмен | Объект и manifest с checksum | эталон `infra/examples/s3` | владелец бакета |
| ETL | Извлечение, преобразование и загрузка в собственную БД потребителя | эталон `infra/examples/etl` | потребитель |
| DLQ потребителя | Сообщение, которое потребитель не смог обработать после исчерпания попыток | [140](140.event-schema.md) | потребитель и оператор replay |
| Повтор публикации | Повторная отправка издателем того же `eventId` | outbox издателя | издатель |
| Оперативная витрина | Собственная БД Reports, а не реплика чужих баз | ADR-012 | Reports |
| Read-replica | Потоковая реплика витрины Reports только для чтения | `reports-db-replica` | инфраструктура поднимает, Reports читает |
| Коллектор | Приёмник OTLP для демонстрации. Не архив телеметрии | `otel-collector` | инфраструктура |
| Draft / agreed / implemented / verified | Предложение, согласие сторон, сделанный артефакт, пройденная проверка | этот комплект | сторона, которая ставит статус |

Пароль, client secret и ключ S3 не являются доменными данными и в журналы не пишутся.
