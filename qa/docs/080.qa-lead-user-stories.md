# 080 — User Stories: QA-лид

> Формат — см. [состав документов](documents-composition.md), документ 080.
> Источник — [vision, разделы 4.2–4.4](vision.md#42-тест-план). Актор H-01, роль R-04 `qa-lead` из [070](070.role-matrix.md), use cases — [060](060.use-cases.md).

**US-QL-01.** As a QA-лид, I want собрать тест-план к итерации или релизу so that команда знала, что проверяем и к какому сроку.
- GWT-1: Given я указал область, ответственного и даты, When создаю план, Then план сохранён в статусе «Черновик».
- GWT-2: Given задан фильтр «тип = smoke, модуль = Reference Manager», When добавляю кейсы фильтром, Then в план попадают все актуальные кейсы под фильтр, а архивные и черновики — нет.
- GWT-3: Given дата окончания раньше даты начала, When сохраняю, Then план не сохранён, поле указано в ответе.

*(→ UC-07; FR-TP-01, FR-TP-02, FR-TP-03)*

**US-QL-02.** As a QA-лид, I want привязать план к итерации Task Tracker и вехе Planning System so that из итерации было видно, какой план её проверял.
- GWT-1: Given я указал идентификатор итерации, When сохраняю план, Then ссылка сохранена и видна в плане, прогонах и дефектах плана.
- GWT-2: Given источник недоступен или чтение не согласовано, When указываю идентификатор вручную, Then ссылка сохранена с пометкой «не проверена».
- GWT-3: Given фильтр собран, When сохраняю его как набор, Then набор доступен для запуска прогона и из CI.

*(→ UC-07; FR-TP-02, FR-TP-05, FR-DAT-02)*

**US-QL-03.** As a QA-лид, I want запускать, завершать и отменять план so that статус плана показывал, идёт ли тестирование.
- GWT-1: Given в плане есть кейсы, When запускаю план, Then статус «Активен» и можно создавать прогоны.
- GWT-2: Given у плана есть незавершённый прогон, When завершаю план, Then операция отклонена с перечнем прогонов.
- GWT-3: Given план активен, When отменяю его, Then статус «Отменён», незавершённые прогоны прерваны.

*(→ UC-08; FR-TP-04)*

**US-QL-04.** As a QA-лид, I want создать прогон и распределить кейсы между тестировщиками so that у каждого был свой список.
- GWT-1: Given план активен и выбрано окружение, When создаю прогон, Then по каждому кейсу создан результат «Не выполнен» с зафиксированной версией.
- GWT-2: Given прогон создан, When назначаю тестировщика на группу кейсов, Then он видит их в своём списке.
- GWT-3: Given после создания прогона кейс изменён, When тестировщик открывает его в прогоне, Then видит версию на момент создания прогона.

*(→ UC-09; FR-RUN-01, FR-RUN-02)*

**US-QL-05.** As a QA-лид, I want создать повторный прогон только по упавшим кейсам so that после исправлений не гонять весь план.
- GWT-1: Given в завершённом прогоне три кейса «Провален» и два «Заблокирован», When создаю повторный прогон, Then в нём ровно эти пять кейсов и ссылка на исходный прогон.
- GWT-2: Given в прогоне нет упавших и заблокированных, When создаю повторный, Then прогон не создан, показано пояснение.
- GWT-3: Given повторный прогон выполнен, When открываю исходный, Then его результаты не изменились.

*(→ UC-14; FR-RUN-07, NFR-05)*

**US-QL-06.** As a QA-лид, I want находить дефекты по проекту, итерации, тестировщику, статусу и серьёзности so that разбирать их перед решением о готовности.
- GWT-1: Given задан фильтр «итерация = X, серьёзность = Blocker, Critical», When открываю список, Then вижу только такие незакрытые дефекты со ссылками на задачи в Task Tracker.
- GWT-2: Given обратный поток из Task Tracker не согласован, When разработчик сообщил об исправлении, Then я перевожу дефект в `FIXED` вручную, а история хранит меня как автора и источник `QA`.

*(→ UC-17, UC-19; FR-DEF-05, FR-DEF-07, FR-DEF-08)*

**US-QL-07.** As a QA-лид, I want видеть итог прогона и плана so that решить, готова ли итерация.
- GWT-1: Given прогон завершён, When открываю сводку, Then вижу число кейсов по статусам, длительность, упавшие кейсы и связанные дефекты.
- GWT-2: Given у плана несколько прогонов, When открываю сводку плана, Then по каждому кейсу показан последний результат.
- GWT-3: Given по плану ещё нет прогонов, When открываю сводку, Then вижу явное сообщение, а не пустую таблицу.

*(→ UC-19; FR-RUN-06)*
