# 080 — User Stories: автоматизатор

> Формат — см. [состав документов](documents-composition.md), документ 080.
> Источник — [vision, разделы 4.3, 5.3 и 6](vision.md#43-прогон-и-автоматический-запуск). Актор H-03, роль R-03 `qa-automation` из [070](070.role-matrix.md), use cases — [060](060.use-cases.md).

**US-AU-01.** As a автоматизатор, I want связать тест-кейс с автотестом по ключу so that результат автотеста записывался в нужный кейс.
- GWT-1: Given автотест с ключом `rm/test_health.py::test_readyz` есть в репозитории, When указываю ключ в кейсе `TC-RM-01`, Then кейс помечен автоматизированным и создана новая версия.
- GWT-2: Given кейс отмечен автоматизированным, When ключ пуст, Then сохранение отклонено.

*(→ UC-06; FR-TC-09)*

**US-AU-02.** As a автоматизатор, I want видеть кейсы, у которых ключ не найден среди автотестов so that вовремя чинить связь после переименований.
- GWT-1: Given в кейсе указан ключ, которого нет в коммите последнего прогона, When открываю список несвязанных ключей, Then вижу этот кейс и ключ.
- GWT-2: Given автотест с таким ключом появился, When исполнитель взял следующий прогон, Then кейс исчезает из списка.
- GWT-3: Given ключ не найден во время прогона, When исполнитель доходит до кейса, Then результат «Заблокирован» с причиной «автотест не найден», а не «Провален».

*(→ UC-06, UC-13; FR-TC-09)*

**US-AU-03.** As a автоматизатор, I want запустить автотесты набора кнопкой на выбранном окружении so that не собирать запуск вручную.
- GWT-1: Given в наборе есть автоматизированные кейсы, When нажимаю «Запустить» и выбираю окружение, Then создан прогон, задание в очереди, я вижу ход выполнения.
- GWT-2: Given этот набор уже исполняется на том же окружении, When запускаю его снова, Then запуск отклонён со ссылкой на идущий прогон.
- GWT-3: Given в наборе есть ручные кейсы, When автотесты завершены, Then ручные кейсы остаются «Не выполнен», а прогон — «Выполняется».

*(→ UC-12; FR-RUN-08, FR-RUN-10)*

**US-AU-04.** As a автоматизатор, I want получать журнал, длительность и причину по каждому автотесту so that разобрать провал без повторного запуска.
- GWT-1: Given автотест завершён, When открываю результат, Then вижу статус, длительность и вложенный журнал.
- GWT-2: Given автотест не уложился в тайм-аут, When открываю результат, Then статус «Провален», причина «тайм-аут».
- GWT-3: Given прогон выполнен исполнителем, When открываю прогон, Then вижу commit SHA автотестов и версии тестируемых подсистем.
- GWT-4: Given автотест использует служебный токен, When читаю журнал, Then токена и секрета клиента в нём нет.

*(→ UC-13; FR-RUN-09, NFR-06, NFR-07)*
