# 080 — User Stories: руководитель проекта

> Формат — см. [состав документов](documents-composition.md), документ 080.
> Источник — [vision, разделы 2 и 3](vision.md#3-пользователи). Актор H-05, роль R-01 `qa-viewer` из [070](070.role-matrix.md), use cases — [060](060.use-cases.md).

**US-PM-01.** As a руководитель проекта, I want видеть состояние тестирования итерации или релиза so that понимать, можно ли выпускать.
- GWT-1: Given к итерации привязан план, When открываю состояние итерации, Then вижу план, его статус, число кейсов по результатам и открытые дефекты по серьёзности.
- GWT-2: Given к итерации не привязан ни один план, When открываю состояние, Then вижу явное сообщение об отсутствии плана.

*(→ UC-19; FR-TP-05)*

**US-PM-02.** As a руководитель проекта, I want перейти от упавшего кейса к дефекту и задаче в Task Tracker so that видеть, кто исправляет проблему.
- GWT-1: Given кейс провален и дефект синхронизирован, When открываю кейс в сводке, Then вижу дефект, его статус и ссылку на «Ошибку».
- GWT-2: Given у меня роль `qa-viewer`, When открываю план или прогон, Then действий изменения в интерфейсе нет, а прямой вызов API возвращает `403`.

*(→ UC-19; FR-DEF-04, FR-SEC-01)*

**US-PM-03.** As a руководитель проекта, I want видеть итог последней приёмки стенда so that понимать, можно ли показывать веху.
- GWT-1: Given последний прогон «Приёмка стенда» получил вердикт, When открываю состояние тестирования, Then вижу вердикт, дату, кто его поставил, число пройденных, упавших и непроверенных кейсов.
- GWT-2: Given после вердикта «Smoke» на стенде стал красным, When открываю состояние, Then вижу предупреждение о красном «Smoke» рядом с вердиктом.

*(→ UC-23; FR-RUN-11)*
