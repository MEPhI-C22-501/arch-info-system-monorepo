# 075 — NFR (Non-Functional Requirements)

> Формат — см. [состав документов](documents-composition.md), документ 075.
> Источник — [vision, раздел 6](vision.md#6-нефункциональные-требования). Решения — [145 ADR](145.architecture-decisions.md), сценарии проверки — [095](095.requirements-check.md).

Номера NFR-01…NFR-19 совпадают с vision 0.3. У каждого требования есть метрика и порог. Колонка «Основание»:

- **расчёт** — порог следует из устройства системы или решения Infra и проверяется тестом без замеров;
- **предложение** — ориентир команды QA; число подтверждается или исправляется замером на стенде к указанной дате. Пороги «для вида» не ставятся: если число зависит от стенда, это записано прямо.

Даты вех интеграций — [160](160.integration-plan.md#1-вехи-интеграций): И-M2 — 2026-11-02, И-M3 — 2026-11-16, И-M4 — 2026-11-30.
