## 3. Порядок реализации

```mermaid
flowchart LR
    A["И-M1: заявка в Infra, вопросы командам"] --> B["I-07 Keycloak"]
    B --> C["I-11 локальный Compose"]
    C --> D["I-12 автотесты RM и TT"]
    D --> E["I-01 «Ошибка» в Task Tracker"]
    E --> F["I-02 опрос статусов"]
    C --> G["I-09 Kafka и I-05 события"]
    G --> H["I-06 REST для хранилища Reports"]
    C --> I["I-04 Reference Manager"]
    C --> J["I-08 MinIO"]
    I --> K["I-03 Planning System, после их API"]
    H --> L["I-10 Smoke в пайплайне"]
    F --> L
    L --> M["И-M5: приёмка стенда"]
```

1. Подать заявку в Infra и отправить вопросы соседям (И-M1): без клиентов Keycloak не работает ничего, остальное начинается на заглушках.
2. Подключить Keycloak и поднять систему локально в общем `compose.yaml`.
3. Автоматизировать кейсы, для которых API уже есть: TC-RM-01…03, TC-RM-05, TC-TT-01, TC-TT-03…05.
4. Создание «Ошибки» — против заглушки по `openapi.yaml` Task Tracker, затем против его стенда; затем опрос статусов.
5. Kafka и события, затем REST для хранилища Reports.
6. Параллельно — кэш Reference Manager и вложения; Planning System — после реализации их API.
7. Включить «Smoke» в пайплайн и провести приёмку стенда на демонстрационных данных.

План и факт по каждому кейсу — [vision, раздел 7](vision.md#7-стартовый-набор-тест-кейсов). На 2026-10-12 ни один автотест QA System не написан.

| TC-RM-01, TC-RM-02, TC-RM-03, TC-RM-05 | Reference Manager | Есть: служебные точки и справочник валют | И-M2 | Автоматизатор | Служебная учётная запись `qa-executor` с ролью чтения и записи справочника |
| TC-RM-04 | Reference Manager | Нет операции восстановления | После появления операции | Автоматизатор | Команда справочников |
| TC-TT-01, TC-TT-03, TC-TT-04, TC-TT-05 | Task Tracker | Есть | И-M3 | Автоматизатор | Права `qa-executor` в Task Tracker |
| TC-TT-02 | Task Tracker | Есть интерфейс | Ручной | Тестировщик | — |

| TC-PS-04, TC-PS-05 | Planning System ↔ Task Tracker | Нет; обмен не согласован (их D-01) | После их соглашения | Автоматизатор | Planning System и Task Tracker |
