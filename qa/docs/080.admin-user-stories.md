# 080 — User Stories: администратор

> Формат — см. [состав документов](documents-composition.md), документ 080.
> Источник — [vision, раздел 3 и FR-TC-06](vision.md#3-пользователи). Актор H-06, роль R-05 `qa-admin` из [070](070.role-matrix.md), use cases — [060](060.use-cases.md).

**US-AD-01.** As a администратор, I want вести шаблоны тест-кейсов so that типовые проверки создавались одинаково.
- GWT-1: Given я заполнил название, поля и шаги по умолчанию, When сохраняю шаблон, Then он доступен тестировщикам при создании кейса.
- GWT-2: Given из шаблона уже созданы кейсы, When изменяю шаблон, Then существующие кейсы не меняются.
- GWT-3: Given шаблон отключён, When тестировщик создаёт кейс, Then шаблона в списке нет.

*(→ UC-21; FR-TC-06)*

**US-AD-02.** As a администратор, I want вести классификаторы, окружения и расписания so that поля кейсов и прогонов имели согласованные значения.
- GWT-1: Given я добавил окружение с адресами подсистем, When тестировщик создаёт прогон, Then окружение доступно для выбора.
- GWT-2: Given значение серьёзности используется в дефектах, When отключаю его, Then в старых дефектах оно сохраняется, а для новых недоступно.
- GWT-3: Given для набора задано расписание, When наступает срок, Then создаётся прогон с источником запуска `SCHEDULE`; если предыдущий запуск ещё идёт, новый пропускается с записью в журнале.

*(→ UC-21; FR-RUN-08, FR-RUN-10)*

**US-AD-03.** As a администратор, I want видеть состояние интеграций и обновлять справочные данные so that быстро находить, почему дефект не ушёл в Task Tracker.
- GWT-1: Given Reference Manager доступен, When запускаю обновление, Then кэш сотрудников и подразделений обновлён, показано время синхронизации.
- GWT-2: Given Reference Manager недоступен, When запускаю обновление, Then остаётся прежний срез, показаны ошибка и время последней успешной синхронизации.
- GWT-3: Given синхронизация дефекта в состоянии `FAILED`, When нажимаю «Повторить», Then запрос отправлен снова без создания дубликата в Task Tracker.
- GWT-4: Given есть неотправленные события, When открываю состояние интеграций, Then вижу их количество и возраст самого старого.

*(→ UC-22, UC-18; FR-DAT-02, NFR-11, NFR-12)*
