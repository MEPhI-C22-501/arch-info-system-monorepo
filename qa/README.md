# QA System — система управления тестированием

Подсистема хранит тест-кейсы, собирает их в тест-планы, проводит ручные и автоматические
прогоны, заводит дефекты по упавшим проверкам с синхронизацией в Task Tracker и служит
приёмочным контуром проекта: 25 кейсов стартового набора проверяют соседние подсистемы на стенде.

Единое имя — **QA System — система управления тестированием**. Другие названия в документах
соседей («сервис тестирования», «управление тестированием и качеством») относятся к ней же.
