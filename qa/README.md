# QA System — система управления тестированием

Подсистема хранит тест-кейсы, собирает их в тест-планы, проводит ручные и автоматические
прогоны и заводит дефекты по упавшим проверкам с синхронизацией в Task Tracker.

## Документы

- [Vision](docs/vision.md) — назначение, процессы, требования, интеграции и стартовый
  набор тест-кейсов для подсистем проекта.
