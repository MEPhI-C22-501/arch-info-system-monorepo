# Чек-лист проверки прототипа

Проверяется существующий HTML-макет, а не backend или реальные интеграции. Сборка и установка зависимостей не нужны.

Из корня репозитория: `open task-tracker/frontend/prototype/index.html` на macOS; на другой ОС откройте этот файл браузером. Откройте DevTools → Console и очистите сообщения. Перед независимым сценарием перезагрузите страницу: данные макета хранятся в памяти вкладки.

| № | Действия | Ожидаемый результат |
|---|---|---|
| 1 | В роли руководителя последовательно открыть бэклог, доску, итерации, уведомления; затем выбрать администратора и открыть настройки | Экраны переключаются, данные отображаются, ошибок JavaScript нет |
| 2 | В бэклоге открыть TT-7; перейти на вкладку истории; закрыть по Esc | Карточка и diff доступны, возврат в бэклог |
| 3 | Открыть исполнимую листовую задачу; добавить комментарий и положительное число часов | Комментарий и запись времени появляются; факт и остаток пересчитываются |
| 4 | Перенести назначенную карточку на доске мышью либо клавишами ←/→ | Статус меняется, карточка перемещается в соответствующую колонку |
| 5 | Попробовать вывести неназначенную карточку из бэклога | Показана ошибка, недопустимый перенос не применяется |
| 6 | Открыть завершённую итерацию; сравнить план и факт | Базовый план и фактические показатели видны отдельно |
| 7 | Нажать уведомление о существующей задаче; закрыть карточку | Открывается связанная карточка, возврат в уведомления |
| 8 | В роли руководителя нажать экспорт, затем «Скачать файл» в диалоге | Скачивается CSV с текущими данными; это демонстрационный формат, не XLSX |
| 9 | Открыть импорт; выполнить «Загрузить корректный файл (демо)», затем на свежей странице вариант с ошибками | Показаны разные результаты; ошибочный вариант не применяет частичные изменения |
| 10 | Выбрать участника, затем администратора | Админ-панель скрыта у участника и доступна администратору |
| 11 | В настройках выполнить синхронизацию; проверить успешный и ошибочный демонстрационные результаты | Журнал показывает результат; при ошибке последние данные сохраняются |
| 12 | Администратором удалить листовой элемент с подтверждением | Элемент исчезает; удаление родителя с детьми не допускается |
