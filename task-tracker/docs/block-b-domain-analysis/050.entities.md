## Статусная модель рабочего элемента

Набор статусов настраивается администратором (см. [070 — RBAC](../block-c-requirements-and-roles/070.role-matrix.md)); ниже — представительный жизненный цикл.

```mermaid
stateDiagram-v2
    [*] --> Бэклог: создан
    Бэклог --> ВРаботе: назначен исполнитель и начата работа
    ВРаботе --> НаПроверке: работа выполнена
    НаПроверке --> ВРаботе: возврат на доработку
    НаПроверке --> Завершена: проверка пройдена
    Бэклог --> Архивирована: отменена без выполнения
    Завершена --> [*]
    Архивирована --> [*]
    Завершена --> УдаленаОкончательно: жёсткое удаление (админ)
    Архивирована --> УдаленаОкончательно: жёсткое удаление (админ)
    УдаленаОкончательно --> [*]
```

Триггеры: переход между рабочими статусами — перемещение карточки на канбан-доске; переход в «Архивирована» — явное действие пользователя с правом; «УдаленаОкончательно» — отдельная защищённая операция, доступна только если у элемента нет дочерних.

## Жизненный цикл итерации

```mermaid
stateDiagram-v2
    [*] --> Запланирована: создана итерация
    Запланирована --> Запланирована: добавление/исключение задач, задание ёмкости
    Запланирована --> Активна: запуск (фиксация базового плана)
    Активна --> Активна: выполнение и контроль показателей
    Активна --> Завершена: завершение периода
    Завершена --> [*]: результаты сохранены
```

## Жизненный цикл уведомления

```mermaid
stateDiagram-v2
    [*] --> Непрочитано: создано после успешного изменения
    Непрочитано --> Прочитано: пользователь отметил
    Прочитано --> [*]
```
