| Задать ёмкость участника | Итерация | Внутренний шаг: отдельного события нет | Планирование (расчёт резерва/перегрузки) |
| Включить / исключить задачу из итерации | Итерация | IterationCompositionChanged | РабочийЭлемент, История изменений, Уведомления |

| Импортировать проверенный `.xlsx` | ПакетИмпорта | Изменения элементов + ExcelImportCompleted | Для каждого элемента — аудит/уведомление; для пакета — итоговый отчёт |

## Технические события

NotificationCreated — техническое событие доставки встроенного уведомления, не самостоятельная бизнес-команда. PlanApplied и ProjectRetired — события границы Planning System. WorkItemFieldsChanged несёт общий diff; TimeLogged/StatusChanged и другие уточняющие события не являются второй записью факта. Каталог и wire-schema — [135](../block-g-api-and-events/135.event-catalog.md), [140](../block-g-api-and-events/140.event-schema.md).
