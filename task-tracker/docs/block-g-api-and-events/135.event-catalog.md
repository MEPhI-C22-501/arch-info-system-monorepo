# 135 — Event Catalog

> Формат — см. [`../documents-composition.md`](../documents-composition.md#135--event-catalog-135event-catalogmd).
> Источник событий — [040 Event Storming](040.event-storming.md). Схемы — [140](140.event-schema.md).

Согласно текущему `../vision.md`, Task Tracker **не публикует** события во внешнюю шину (Kafka) — обмен с сервисом отчётности реализован синхронным read-only API ([130](130.api-contracts.md)), а не событийным потоком. Ниже — каталог **внутренних** доменных событий (используются внутри приложения для истории изменений и уведомлений); вынесение части из них во внешнюю шину — предмет будущего решения, не зафиксированного в vision.md.

| Событие | Издатель | Подписчики (внутренние) | Триггер | Критичность |
|---|---|---|---|---|
| `WorkItemCreated` | Модуль рабочих элементов | Аудит | Успешное создание элемента | Средняя |
| `WorkItemFieldsChanged` | Модуль рабочих элементов | Аудит, Уведомления | Сохранение изменений карточки | Высокая |
| `AssigneeChanged` | Модуль рабочих элементов | Аудит, Уведомления | Назначение/переназначение исполнителя | Высокая |
| `StatusChanged` | Модуль рабочих элементов | Аудит, Уведомления, Модуль итераций | Перемещение по канбан-доске | Высокая |
| `TimeLogged` | Модуль трудозатрат | Модуль рабочих элементов (пересчёт) | Регистрация записи времени | Средняя |
| `AttachmentAdded` / `AttachmentRemoved` | Модуль вложений | Аудит, Уведомления | Действие пользователя | Низкая |
| `IterationActivated` | Модуль итераций | Модуль рабочих элементов (снимок плана) | Запуск итерации | Высокая |
| `IterationCompleted` | Модуль итераций | Модуль рабочих элементов (возврат незавершённых в бэклог) | Завершение итерации | Высокая |
| `WorkItemHardDeleted` | Модуль рабочих элементов | Каскадная очистка зависимых данных | Подтверждённое жёсткое удаление | Критичная |
| `BugCreatedFromTesting` | Интеграционный модуль (сервис тестирования) | Аудит | Успешный вызов `POST /api/v1/bugs` | Средняя |
| `NotificationCreated` | Модуль уведомлений | UI (список уведомлений) | Любое из вышеуказанных событий после успешной операции | Средняя |
