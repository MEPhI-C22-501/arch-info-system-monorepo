# 135 — Event Catalog

> Формат — см. [`../documents-composition.md`](../documents-composition.md#135--event-catalog-135event-catalogmd).
> Источник событий — [040 Event Storming](../block-b-domain-analysis/040.event-storming.md). Схемы — [140](140.event-schema.md).

Согласно текущему `../vision.md`, Task Tracker **не публикует** события во внешнюю Kafka: обмен с сервисом отчётности реализован входящим read-only API ([130](130.api-contracts.md)). Ниже — каталог внутренних доменных событий. Они доставляются внутри транзакционной границы приложения согласно ADR-007; Kafka topic, partition и внешние подписчики отсутствуют. Вынос событий во внешнюю шину потребует отдельного ADR.

| Событие | Издатель | Подписчики (внутренние) | Триггер | Бизнес-смысл | Критичность |
|---|---|---|---|---|---|
| `WorkItemCreated` | Рабочие элементы | Аудит; Уведомления при наличии исполнителя | Элемент сохранён | Новая работа зарегистрирована | Высокая |
| `WorkItemFieldsChanged` | Рабочие элементы | Аудит, Уведомления | Поля/приоритет/срок успешно изменены | Карточка получила новую версию | Высокая |
| `AssigneeChanged` | Рабочие элементы | Аудит, Уведомления новому и текущему исполнителю | Назначение/переназначение | Изменилась ответственность | Высокая |
| `StatusChanged` | Рабочие элементы | Аудит, Уведомления, Итерации | Переход статуса сохранён | Изменилось состояние выполнения | Высокая |
| `HierarchyChanged` | Рабочие элементы | Аудит, Уведомления | Создание/перенос дочерней связи | Изменилась декомпозиция | Высокая |
| `CommentChanged` | Совместная работа | Аудит, Уведомления | Комментарий создан/изменён/удалён | Изменилось обсуждение | Средняя |
| `TimeLogged` | Трудозатраты | Пересчёт, Аудит, Уведомления | Запись времени сохранена | Изменились факт и остаток | Высокая |
| `AttachmentChanged` | Совместная работа | Аудит, Уведомления | Файл добавлен/удалён | Изменились материалы карточки | Средняя |
| `IterationCompositionChanged` | Итерации | Аудит, Уведомления | Элемент включён/исключён | Изменился план итерации | Высокая |
| `IterationActivated` | Итерации | Baseline/Audit | Активация в транзакции | Зафиксирован базовый план | Критичная |
| `IterationCompleted` | Итерации | Plan-fact/Audit | Завершение в транзакции | Зафиксирован результат | Критичная |
| `WorkItemHardDeleted` | Рабочие элементы | Уведомления | Подтверждённое атомарное удаление | Работа удалена безвозвратно; notification хранит snapshot | Критичная |
| `BugCreatedFromTesting` | Интеграция | Аудит, Уведомления | Успешный `POST /api/v1/bugs` | Внешний дефект зарегистрирован | Высокая |
| `DirectorySynchronized` | Интеграция | Кэш, Admin UI | Получена новая версия справочника | Оргданные обновлены | Средняя |
| `ExcelImportCompleted` | Импорт/экспорт | Аудит, UI | Валидированный пакет применён | Пакетное изменение завершено с отчётом | Высокая |
| `NotificationCreated` | Уведомления | UI | Уведомление записано в той же транзакции, что изменение | Пользователь может увидеть committed-изменение | Высокая |
