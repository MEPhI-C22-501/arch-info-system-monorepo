# 130 — API Contracts

> Формат — см. [`../documents-composition.md`](../documents-composition.md#130--api-contracts-130api-contractsmd).
> Источник — [`../vision.md`](../vision.md), раздел «Требования к интеграциям».

Машиночитаемый контракт Task Tracker: [`openapi.yaml`](openapi.yaml), версия `1.0.0-draft`. Ниже приведены ключевые примеры входящих API и зависимый исходящий контракт сервиса справочников. Точная схема аутентификации и контракт владельца справочников остаются открытыми и помечены как draft.

## Внешние контракты

**`POST /api/v1/bugs`** — создание ошибки сервисом тестирования (сервисная аутентификация).

Запрос:
```json
{
  "externalSource": "test-management",
  "externalDefectId": "TM-4821",
  "title": "Экспорт зависает на большом файле",
  "description": "Шаги воспроизведения...",
  "severity": "high",
  "environment": "staging-2",
  "testRunUrl": "https://test-mgmt.example/runs/998"
}
```

Успешный ответ `201 Created`:
```json
{ "id": "b3b9b1b0-...", "status": "created", "workItemUrl": "/work-items/b3b9b1b0-..." }
```

Повторный запрос с той же парой (`externalSource`, `externalDefectId`) → `200 OK`:
```json
{ "id": "b3b9b1b0-...", "status": "already-exists", "workItemUrl": "/work-items/b3b9b1b0-..." }
```

Ошибка валидации `422 Unprocessable Entity`:
```json
{ "correlationId": "c7f1...", "errors": [{ "field": "title", "reason": "required" }] }
```

**`GET /api/v1/reports/work-items`** — чтение данных сервисом отчётности (сервисная аутентификация, только чтение).

Параметры запроса: `periodFrom`, `periodTo`, `projectId`, `iterationId`, `type`, `status`, `assigneeId`, `page`, `pageSize`.

Успешный ответ `200 OK`:
```json
{
  "items": [
    { "id": "...", "projectId": "...", "type": "Задача", "status": "В работе", "assigneeId": "...", "dueDate": "2026-10-10", "plannedHours": 8, "actualHours": 5, "remainingHours": 3, "iterationId": "..." }
  ],
  "page": 1, "pageSize": 100, "totalPages": 4
}
```

Ошибка авторизации `403 Forbidden`:
```json
{ "correlationId": "c7f2...", "errors": [{ "field": "scope", "reason": "insufficient_scope" }] }
```

## Внутренние CRUD-эндпоинты (для UI, состав ориентировочный)

| Метод и путь | Назначение |
|---|---|
| `GET/POST /api/v1/work-items` | список с фильтрами / создание |
| `GET/PATCH/DELETE /api/v1/work-items/{id}` | карточка / изменение / жёсткое удаление |
| `POST /api/v1/work-items/{id}/comments` | добавить комментарий |
| `GET/POST /api/v1/work-items/{id}/attachments`, `GET/DELETE /api/v1/work-items/{id}/attachments/{attachmentId}` | список, загрузка, скачивание и удаление вложений |
| `POST /api/v1/work-items/{id}/time-logs` | зарегистрировать время |
| `GET /api/v1/work-items/{id}/history` | история изменений |
| `POST/PATCH /api/v1/iterations`, `POST /api/v1/iterations/{id}/activate`, `POST /api/v1/iterations/{id}/complete` | управление итерациями |
| `GET/PATCH /api/v1/notifications` | список уведомлений / отметка прочитанным |
| `GET/POST/PATCH /api/v1/admin/statuses`, `.../admin/priorities` | настройка справочников доски |
| `POST /api/v1/exports/work-items`, `POST /api/v1/imports/work-items` | сформировать `.xlsx`; проверить и применить импорт с отчётом |

Для отчётности спецификация также предусматривает read-only ресурсы `/api/v1/reports/iterations` и `/api/v1/reports/time-logs`: без дат трудозатрат и состава итераций сервис отчётности не сможет вычислить требуемые показатели по периоду.

## Исходящий зависимый контракт справочников (draft)

Task Tracker вызывает версионированный endpoint владельца справочников, логически эквивалентный `GET /api/v1/directory/snapshot?sinceVersion=...`. Ответ должен содержать `version` и массивы `users`, `teams`, `departments`; у каждой записи обязательны стабильный внешний ID, отображаемое имя и `active`. Для вызова задаются timeout и ограниченные повторы; после исчерпания попыток продолжает использоваться последняя успешная версия. URL, схема сервисной аутентификации и владелец контракта должны быть подтверждены до снятия статуса draft.

**Версионирование:** путь содержит мажорную версию (`/api/v1/`), контракт следует semver; обратная совместимость сохраняется в пределах мажорной версии.
