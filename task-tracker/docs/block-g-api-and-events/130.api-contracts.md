# 130 — API Contracts

> Формат — см. [`../documents-composition.md`](../documents-composition.md#130--api-contracts-130api-contractsmd).
> Источник — [`../vision.md`](../vision.md), раздел «Требования к интеграциям».

Полная OpenAPI-спецификация не выпущена (реализация ещё не начата); ниже — контракт на уровне эндпоинтов для двух внешних интеграций, зафиксированных в vision.md, плюс перечень внутренних CRUD-эндпоинтов для UI.

## Внешние контракты

**`POST /api/v1/bugs`** — создание ошибки сервисом тестирования (сервисная аутентификация).

Запрос:
```json
{
  "externalSource": "test-management",
  "externalDefectId": "TM-4821",
  "title": "Экспорт зависает на большом файле",
  "description": "Шаги воспроизведения...",
  "severity": "high",
  "environment": "staging-2",
  "testRunUrl": "https://test-mgmt.example/runs/998"
}
```

Успешный ответ `201 Created`:
```json
{ "id": "b3b9b1b0-...", "status": "created", "workItemUrl": "/work-items/b3b9b1b0-..." }
```

Повторный запрос с тем же `externalDefectId` → `200 OK`:
```json
{ "id": "b3b9b1b0-...", "status": "already-exists", "workItemUrl": "/work-items/b3b9b1b0-..." }
```

Ошибка валидации `422 Unprocessable Entity`:
```json
{ "correlationId": "c7f1...", "errors": [{ "field": "title", "reason": "required" }] }
```

**`GET /api/v1/reports/work-items`** — чтение данных сервисом отчётности (сервисная аутентификация, только чтение).

Параметры запроса: `period`, `projectId`, `iterationId`, `type`, `status`, `assigneeId`, `page`, `pageSize`.

Успешный ответ `200 OK`:
```json
{
  "items": [
    { "id": "...", "type": "Задача", "status": "В работе", "plannedHours": 8, "actualHours": 5, "remainingHours": 3, "iterationId": "..." }
  ],
  "page": 1, "pageSize": 100, "totalPages": 4
}
```

Ошибка авторизации `403 Forbidden`:
```json
{ "correlationId": "c7f2...", "error": "insufficient_scope" }
```

## Внутренние CRUD-эндпоинты (для UI, состав ориентировочный)

| Метод и путь | Назначение |
|---|---|
| `GET/POST /api/v1/work-items` | список с фильтрами / создание |
| `GET/PATCH/DELETE /api/v1/work-items/{id}` | карточка / изменение / жёсткое удаление |
| `POST /api/v1/work-items/{id}/comments` | добавить комментарий |
| `POST /api/v1/work-items/{id}/attachments` | прикрепить файл |
| `POST /api/v1/work-items/{id}/time-logs` | зарегистрировать время |
| `GET /api/v1/work-items/{id}/history` | история изменений |
| `POST/PATCH /api/v1/iterations`, `POST /api/v1/iterations/{id}/activate`, `POST /api/v1/iterations/{id}/complete` | управление итерациями |
| `GET/PATCH /api/v1/notifications` | список уведомлений / отметка прочитанным |
| `GET/POST/PATCH /api/v1/admin/statuses`, `.../admin/priorities` | настройка справочников доски |

**Версионирование:** путь содержит мажорную версию (`/api/v1/`), контракт следует semver; обратная совместимость сохраняется в пределах мажорной версии.
