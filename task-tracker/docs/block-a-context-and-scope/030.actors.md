# 030 — Actors

> Формат — см. [`../documents-composition.md`](../documents-composition.md#030--actors-030actorsmd).
> Источник — [`../vision.md`](../vision.md). См. также [020 — System Context](020.system-context.md).

| Актор | Описание | Основные цели / функции в системе |
|---|---|---|
| Участник команды | Исполнитель, работающий над назначенными рабочими элементами | Просматривает свои задачи, меняет статус на канбан-доске, регистрирует трудозатраты, комментирует, прикрепляет файлы, читает уведомления |
| Руководитель / планировщик | Ведёт бэклог и итерации | Приоритизирует, назначает исполнителей, оценивает ёмкость, планирует и контролирует итерации, декомпозирует крупную работу |
| Администратор | Настраивает процесс и доступ | Управляет статусами, типами, ролями и правами; выполняет ручной запуск синхронизации справочников; выполняет жёсткое удаление |
| Сервис тестирования (внешняя система) | Автоматически регистрирует дефекты | Вызывает API создания «Ошибки»; протокол REST + сервисная аутентификация; сценарий — по результатам тестового прогона создаёт задачу без участия человека |
| Сервис отчётности (внешняя система, `reports`) | Строит отчёты по данным трекера | Вызывает read-only REST API с фильтрами/пагинацией; сценарий — периодический опрос и построение витрины |
| Сервис справочников (внешняя система) | Источник данных об организации | Отдаёт список пользователей/команд/подразделений; протокол REST; сценарий — периодическая синхронизация, инициируемая Task Tracker |
