# 020 — System Context

> Формат — см. [`../documents-composition.md`](../documents-composition.md#020--system-context-020system-contextmd).
> Источник — [`../vision.md`](../vision.md), сверено с [`../system-requirements.md`](../system-requirements.md).
> См. также [010 — Глоссарий](010.glossary.md).

Task Tracker — самостоятельный модуль ERP-системы. Внутри границ модуля: бэклог, канбан-доска, карточка рабочего элемента, иерархия, комментарии, вложения, история изменений, учёт трудозатрат, итерации, уведомления. За границами: собственная аутентификация (делегирована Keycloak), собственный реестр пользователей/оргструктуры (делегирован сервису справочников), построение отчётов (делегировано сервису отчётности), доставка и эксплуатация (делегированы Infra).

```mermaid
flowchart TB
    subgraph Users["Люди"]
        Member["Участник команды"]
        Lead["Руководитель / планировщик"]
        Admin["Администратор"]
    end

    subgraph TT["Task Tracker"]
        Backlog["Бэклог"]
        Board["Канбан-доска"]
        Card["Карточка рабочего элемента"]
        Iterations["Итерации"]
        Notify["Уведомления"]
        Audit["История изменений"]
    end

    KC["Keycloak — идентификация"]
    Tests["Сервис тестирования — источник ошибок"]
    Reports["Сервис отчётности — потребитель данных"]
    Refs["Сервис справочников — пользователи, команды, подразделения"]

    Member --> TT
    Lead --> TT
    Admin --> TT
    TT -->|проверка токена и прав| KC
    Tests -->|создание ошибки, API| TT
    TT -->|данные для отчётов, API| Reports
    Refs -->|пользователи / команды / подразделения| TT
```

| Внешняя система | Роль | Тип интеграции |
|---|---|---|
| Keycloak | Подтверждение личности пользователя, выдача и проверка токенов | OpenID Connect, синхронный вызов на каждый запрос |
| Сервис тестирования | Источник рабочих элементов типа «Ошибка» по результатам тестовых прогонов | REST API (входящий вызов в Task Tracker), идемпотентный |
| Сервис отчётности (`reports`) | Потребитель данных о проектах, эпиках, задачах, итерациях, трудозатратах | REST API только для чтения (исходящий ответ Task Tracker), с фильтрами и пагинацией |
| Сервис справочников | Источник пользователей, команд и подразделений для назначения исполнителей | REST API (исходящий вызов из Task Tracker), периодическая синхронизация с кэшем |
| Infra | Развёртывание, CI/CD, сеть, постоянные хранилища | Вне функциональных границ модуля |
