# Сценарии качества Task Tracker

| ID | Стимул и условия | Реакция и измеримый критерий | Проверка |
|---|---|---|---|
| QS-TT-01 | Отправка пропустила цикл из-за отказа брокера | Первая запись после ошибки остаётся `PENDING`, её ID сохраняется, следующая запись той же задачи ждёт. После восстановления обе уходят по порядку | `ReviewIntegrationTest.failedDeliveryAndRestartPreserveAggregateOrderAndSkipAcknowledgedEvents` |
| QS-TT-02 | Процесс отправки перезапустился после сохранённого ACK | Для первой записи число повторных вызовов в новом процессе равно нулю, вторая запись отправляется один раз. Если ACK и коммит разделил сбой, повтор несёт исходный `eventId` | Тот же сценарий и `rollbackDoesNotLeakAnOutboxEventAndReplayKeepsItsIdentifier` |
| QS-TT-03 | В очереди 21 доступное событие разных карточек | Первый проход подтверждает 20 записей, в очереди остаётся одна. Второй проход подтверждает её, в очереди остаётся 0 | `ReviewIntegrationTest.backlogLargerThanOneBatchContinuesOnTheNextPass` |
| QS-TT-04 | Пересчёт итерации с родителем и потомком при неизменных входах | Два пересчёта дают один результат. При плане 8 ч и записях 3 и 2 ч итог равен 5 ч. Часы относятся к авторам записей | `IterationMetricsCalculatorTest.factsBelongToTheirAuthorsAndSurviveDecompositionWithoutDoubleCounting` |
| QS-TT-05 | Хранилище отклоняет загрузку или скачивание | API возвращает 503, новой записи вложения нет, резервация сохраняется для очистки. В браузере карточка открыта, ошибка видна, повтор после восстановления показывает файл | `ReviewIntegrationTest.unavailableS3ReturnsServiceUnavailableAndLeavesNoAttachment`, Playwright `attachment storage failure leaves the card usable and allows retry` |
| QS-TT-06 | Вторая страница справочника недоступна | Синхронизация возвращает ошибку, число активных записей предыдущего кэша остаётся прежним | `ReviewIntegrationTest.failedSecondDirectoryPagePreservesPreviousUsers` |

Порог размера очереди и p95 времени разбора для рабочей нагрузки остаются в DEC-TT-07. QS-TT-03 проверяет границу размера одной пачки.
