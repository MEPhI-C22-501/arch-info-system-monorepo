# 095 — Traceability Matrix

> Формат — см. [`../documents-composition.md`](../documents-composition.md#095--traceability-matrix-095requirements-checkmd).
> Источники — [`../vision.md`](../vision.md) и [`../system-requirements.md`](../system-requirements.md).
> ID введены для трассировки, поскольку базовые документы не нумеруют отдельные требования.

Колонка «Проверка» указывает проектный сценарий приёмки. До появления исполняемых тестов статус означает покрытие проектными артефактами, а не факт реализации.
