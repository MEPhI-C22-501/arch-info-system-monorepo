# 110 — UI/UX прототип

> Формат — см. [`../documents-composition.md`](../documents-composition.md#110--uiux-прототип-110ui-uxmd).
> Источник — [`../vision.md`](../vision.md). Экраны привязаны к [080 user stories](080.member-user-stories.md)
> и [060 use cases](060.use-cases.md); интерактивная версия — [115](115.live-prototype.md).

**Принципы:** консистентность оформления карточек и списков; обратная связь на каждое действие (сохранение, ошибка, перегрузка ёмкости); предсказуемость переходов канбан-доски; минимизация когнитивной нагрузки (не показывать поля, не относящиеся к типу элемента); accessibility (контраст, управление с клавиатуры для перетаскивания карточек).

## Ключевые экраны

| Экран | Структура | Функциональные элементы | Состояния |
|---|---|---|---|
| Бэклог | таблица/список + панель фильтров | фильтр по типу/статусу/приоритету/исполнителю/итерации; создание элемента; переход в карточку | loading (скелетон строк); empty (нет элементов по фильтру); error (не удалось загрузить) |
| Канбан-доска | колонки по активным статусам | перетаскивание карточек; фильтры по исполнителю/приоритету/итерации; краткая карточка (ID, наименование, исполнитель, приоритет, срок, остаток часов) | loading; empty (нет активных статусов); error (перемещение отклонено — карточка возвращается с пояснением) |
| Карточка рабочего элемента | шапка (тип, статус, приоритет) + вкладки | поля карточки; блок родитель/дети; вложения; трудозатраты (список + форма); комментарии; история изменений (список + diff); смена статуса | loading; error валидации (например, срок раньше даты начала); автосохранение черновика описания |
| Страница итерации | реквизиты + список задач + показатели | добавление/исключение задач; ёмкость участников и нагрузка; план-факт после завершения; запуск/завершение итерации | empty (итерация без задач); error (запуск при перегрузке требует подтверждения) |
| Уведомления | список, сортировка по дате | отметка «прочитано»; переход в связанную карточку | empty (нет уведомлений) |
| Админ-панель | статусы, типы, роли и права | создание/переименование/порядок/деактивация статусов; настройка прав по ролям; запуск синхронизации справочников; жёсткое удаление | error (синхронизация недоступна — показывается время последней успешной синхронизации) |

**Навигация:** Бэклог ↔ Карточка ↔ История/Diff; Канбан-доска ↔ Карточка; Страница итерации → Карточка задачи из списка; Уведомление → Карточка. Админ-панель — отдельный раздел, виден только администратору.

**Контекстное управление по правам:** действия «жёсткое удаление», «настройка статусов/типов», «управление правами» скрыты и дополнительно проверяются на сервере (см. [075 NFR-003](075.nfr.md)) для ролей без соответствующего права.

**UX-особенности:** автосохранение описания карточки; подтверждение перед жёстким удалением (модальное окно с явным предупреждением о необратимости); предупреждение о перегрузке ёмкости до запуска итерации, а не после.

**Привязка к user stories:** Бэклог → US-M1; Канбан-доска → US-M2; Карточка → US-M3, US-L4; Страница итерации → US-L1, US-L3; Уведомления → US-M4; Админ-панель → US-A1, US-A2.
