# 110 — UI/UX прототип

> Формат — см. [`../documents-composition.md`](../documents-composition.md#110--uiux-прототип-110ui-uxmd).
> Источник — [`../vision.md`](../vision.md). Экраны привязаны к [080 user stories](../block-c-requirements-and-roles/080.member-user-stories.md)
> и [060 use cases](../block-b-domain-analysis/060.use-cases.md); интерактивная версия — [115](115.live-prototype.md).

**Принципы:** консистентность оформления карточек и списков; обратная связь на каждое действие (сохранение, ошибка, перегрузка ёмкости); предсказуемость переходов канбан-доски; минимизация когнитивной нагрузки (не показывать поля, не относящиеся к типу элемента); accessibility (контраст, управление с клавиатуры для перетаскивания карточек).

## Ключевые экраны

| Экран | Структура | Функциональные элементы | Состояния |
|---|---|---|---|
| Бэклог | таблица/список + панель фильтров | фильтр по типу/статусу/приоритету/исполнителю/итерации; создание элемента; действия импорта и экспорта Excel; переход в карточку | loading (скелетон строк); empty (нет элементов по фильтру); error (не удалось загрузить; импорт отклонён — отчёт об ошибках) |
| Канбан-доска | колонки по активным статусам | перетаскивание карточек; фильтры по исполнителю/приоритету/итерации; краткая карточка (ID, наименование, исполнитель, приоритет, срок, остаток часов) | loading; empty (нет активных статусов); error (перемещение отклонено — карточка возвращается с пояснением) |
| Карточка рабочего элемента | шапка (тип, статус, приоритет) + вкладки | поля карточки; блок родитель/дети; вложения; трудозатраты (список + форма); комментарии; история изменений (список + diff); смена статуса | loading; error валидации (например, срок раньше даты начала); автосохранение черновика описания |
| Страница итерации | реквизиты + список задач + показатели | добавление/исключение задач; ёмкость участников и нагрузка; план-факт после завершения; запуск/завершение итерации | empty (итерация без задач); warning (перегрузка показана до запуска; автоматический запрет не задан требованиями); error (операция не сохранена) |
| Уведомления | список, сортировка по дате | отметка «прочитано»; переход в связанную карточку | empty (нет уведомлений) |
| Админ-панель | статусы, пять типов, роли и права | создание/переименование/порядок/деактивация статусов; доступность пяти типов без добавления шестого; локальный допуск и права; read-only оргданные; запуск синхронизации | error (синхронизация недоступна — показывается время последней успешной синхронизации) |

**Навигация:** Бэклог ↔ Карточка ↔ История/Diff; Канбан-доска ↔ Карточка; Страница итерации → Карточка задачи из списка; Уведомление → Карточка. Админ-панель — отдельный раздел, виден только администратору.

**Контекстное управление по правам:** действие «жёсткое удаление» размещается в карточке рабочего элемента, а «настройка статусов/пяти типов» и «управление правами» — в админ-панели. Все эти действия скрыты и дополнительно проверяются на сервере (см. [075 NFR-003](../block-c-requirements-and-roles/075.nfr.md)) для ролей без соответствующего права.

**UX-особенности:** автосохранение локального черновика описания без создания серверной версии до явного сохранения; предпросмотр поддерживаемых вложений; подтверждение перед жёстким удалением; предупреждение о перегрузке ёмкости до запуска итерации.

**Привязка к user stories:** Бэклог → US-M1, US-L5; Канбан-доска → US-M2; Карточка → US-M3, US-L4; Страница итерации → US-L1, US-L3; Уведомления → US-M4; Админ-панель → US-A1, US-A2.
