Статическая проверка не подтверждает безопасность всего стенда.

## Чек-лист и результаты

| Проверка | Свидетельство / результат | Ограничение |
|---|---|---|
| JWT и роли | `SecurityConfig`: проверка подписи через JWKS, issuer/exp/audience; `AccessService`: локальный допуск и роли сервисов | 401/403 на реальном Keycloak требуют стенда |
| Чужие задачи (IDOR) | `AccessService.itemRead/itemWrite` запрещают MEMBER доступ к чужому исполнителю; `AccessServiceTest` проверяет запрет и доступ к своей задаче | Дочерние элементы в `WorkItemService.view` и агрегаты итераций требуют отдельной сквозной проверки видимости |
| Комментарии и вложения | `CollaborationService` проверяет чтение родительской задачи, ID вложения/комментария выбирает вместе с work_item_id; управление чужим комментарием требует отдельного права | Не покрыта вся матрица операций в HTTP-тестах |
| XSS | Поля текста выводятся React как текст; HTML-вложение ранее открывалось в iframe без sandbox | Добавлена изоляция iframe без `allow-scripts`/`allow-same-origin`, регрессия `AttachmentFrame.test.tsx`; браузерный прогон ещё нужен |
| CSRF | Клиент передаёт явный Bearer в Authorization; CSRF отключён для API в `SecurityConfig` | Переход на cookie-аутентификацию потребует CSRF-защиты; отсутствие сессионного cookie необходимо проверить на стенде |
| SQL-инъекции | В проверенных сервисах значения передаются параметрами `?`; сортировка — switch, имена таблиц activeReference — константы вызова | Динамические SQL-фрагменты нельзя принимать из клиентского ввода |
| Excel: формулы и структура | `ExcelService` отвергает FORMULA, неверные заголовки, ID, даты и часы; экспорт использует строковые ячейки, не формулы. `ExcelServiceTest` проверяет отклонение формулы до изменения задач | Нет собственного лимита строк/листа; Multipart ограничен 20 MB, для ZIP-bomb используется защита POI, стресс-проверка не выполнена |
| Excel: права и атомарность | Требуется `excel.import`; проверяются версии, при ошибке записи транзакция помечается rollback-only | Импорт вызывает createAs/updateAs напрямую; отдельные item.create/item.update и права на чужую задачу при изменении матрицы не проверяются. Начальная роль импорта — LEAD. До расширения права нужен отдельный регрессионный фикс; rollback требует интеграционного теста БД |
| Загрузка файлов | Лимит 10 MiB в `CollaborationService`, multipart 20 MB; имя очищается от CR/LF и разделителей пути; хранение bytea, скачивание Content-Disposition attachment | MIME поступает от клиента; allowlist/проверка содержимого/антивирус ещё отсутствуют, MinIO/ACL не реализованы |
| Секреты и экспозиция | Compose публикует порты только на loopback; демонстрационные пользователи и пароли явно обозначены | Dev-секреты и HTTP не подходят общему стенду; `DEV_DIRECTORY` должен быть выключен вне dev |
| Зависимости | npm audit выявил high в транзитивном source-map-js 1.2.1 (GHSA-68fv-2mgg-jv7q); устранён точечным обновлением lock-файла до 1.2.2; повторный аудит: 0 уязвимостей | Это зависимость инструментов сборки; Java-зависимости не проверены по advisory database |

## Воспроизведение и дальнейшая приёмка

```sh
# из task-tracker/backend
mvn -B checkstyle:check test
# из task-tracker/frontend
npm ci
npm run lint
npm test
npm run build
npm audit
# из task-tracker
docker compose config --quiet
```

После запуска чистого стенда: получить JWT member/lead/admin и сервисов; проверить 401 без токена и с неправильными issuer/audience/exp; member запросить/изменить чужую задачу, комментарий, время и вложение и получить 403; проверить сервисные роли и отозванный локальный допуск. Импортировать повреждённый, формульный, устаревший и слишком большой XLSX, сравнить БД до/после отказа. Загрузить файл сверх лимита, HTML со скриптом и имя с CR/LF; проверить запрет исполнения в preview. Логи сохранять без JWT и содержимого файлов.

Владельцы оставшихся проверок: Task Tracker — права, Excel, файлы и браузерные сценарии; Infra — JWT общего стенда, секреты, TLS и ACL MinIO. Контрольный срок — И-M3, до совместной приёмки И-M4. NFR-003 остаётся partial; полный пентест и отсутствие уязвимостей не заявляются.
