## Сервисные роли и владение планом

JWT client roles относятся к audience task-tracker: testing-service → POST bugs и read-only reports; reports-service → read-only reports; planning-service → PUT/DELETE planning/projects и GET facts/reports. Сервисы не используют UI CRUD и человеческий local_access. Только администратор с directory.admin читает outbox и запускает replay.

Проект/эпик создаётся Planning System. Для связанной задачи плановые title/parent/assignee/dates/plannedHours защищены; статус, описание и приоритет остаются операционными. Hard delete planning binding запрещён. HR-профиль, пароль и оргструктура не администрируются здесь.
