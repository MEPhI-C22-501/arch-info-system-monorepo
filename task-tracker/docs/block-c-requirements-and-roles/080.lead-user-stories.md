# 080 — User Stories: руководитель / планировщик

> Формат — см. [`../documents-composition.md`](../documents-composition.md#080--user-stories-080actor-user-storiesmd).
> Источник — [`../vision.md`](../vision.md). Роль — [070 RBAC](070.role-matrix.md), use cases — [060](../block-b-domain-analysis/060.use-cases.md).

**US-L1.** Как руководитель, я хочу видеть загрузку каждого участника при формировании итерации, чтобы не допустить перегрузку команды.
- GWT-1: Дано заданы ёмкости участников и отобраны задачи, Когда сумма оценок превышает ёмкость участника, Тогда система показывает перегрузку до запуска итерации.
- GWT-2: Дано нагрузка в пределах ёмкости, Когда я просматриваю сводку, Тогда вижу свободный резерв по каждому участнику.
*(→ UC-8)*

**US-L2.** Как руководитель, я хочу декомпозировать крупную задачу на дочерние элементы, чтобы контролировать выполнение по частям.
- GWT-1: Дано задача открыта, Когда я создаю дочерний элемент, Тогда он появляется в иерархии и в бэклоге с собственными статусом, исполнителем и оценкой.
- GWT-2: Дано попытка сделать элемент потомком самого себя, Когда я подтверждаю связь, Тогда система отклоняет операцию.
*(→ UC-4)*

**US-L3.** Как руководитель, я хочу сравнить базовый план итерации с фактом после её завершения, чтобы оценить точность планирования.
- GWT-1: Дано итерация была активирована с зафиксированным базовым планом, Когда итерация завершается, Тогда система сохраняет сравнение плана и факта по задачам, исполнителям и итерации в целом.
- GWT-2: Дано в итерации остались незавершённые элементы, Когда итерация завершается, Тогда они остаются в бэклоге и доступны для следующего планирования, а завершённая итерация сохраняет свою историю состава.
*(→ UC-10)*

**US-L4.** Как руководитель, я хочу видеть diff каждого изменения карточки, чтобы понимать, что и когда изменилось.
- GWT-1: Дано у карточки есть история изменений, Когда я открываю конкретную запись, Тогда вижу предыдущие и новые значения с визуальным выделением различий.
- GWT-2: Дано у меня нет права просмотра элемента, Когда я запрашиваю его историю напрямую, Тогда сервер отклоняет запрос независимо от видимости ссылки в UI.
*(→ UC-11)*

**US-L5.** Как руководитель, я хочу выгрузить рабочие элементы в Excel, отредактировать их пакетно и загрузить файл обратно, чтобы вносить массовые правки без ручного повторения действий в интерфейсе.
- GWT-1: Дано я экспортировал элементы в `.xlsx` и изменил допустимые значения, Когда я загружаю файл обратно, Тогда система проверяет структуру и создаёт/обновляет элементы по идентификатору.
- GWT-2: Дано файл содержит некорректные строки, Когда я его загружаю, Тогда система не применяет некорректные строки частично и показывает отчёт с перечнем ошибок.
*(→ UC-19)*

**US-L6.** Как руководитель, я хочу создавать, приоритизировать и назначать рабочие элементы, чтобы бэклог отражал согласованный порядок работы.
- GWT-1: Дано у меня есть право создания, Когда я сохраняю элемент с обязательным наименованием и одним из пяти типов, Тогда он получает уникальный ID и появляется в бэклоге.
- GWT-2: Дано элемент существует, Когда я меняю приоритет или исполнителя, Тогда изменение сохраняется, попадает в аудит и уведомляет текущего или нового исполнителя.
*(→ UC-1, UC-2)*
