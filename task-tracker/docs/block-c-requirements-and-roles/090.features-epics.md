# 090 — Epics / Features

> Формат — см. [`../documents-composition.md`](../documents-composition.md#090--epics--features-090features-epicsmd).
> Источник — [`../vision.md`](../vision.md). Связанные user stories — [080](080.member-user-stories.md) и соседние файлы.

Все перечисленные возможности входят в обязательную область vision и критериев приёмки, поэтому имеют приоритет **Must**. Веха задаёт порядок разработки, а не исключение из объёма.

| Эпик | Описание | Приоритет (MoSCoW) | User stories | Веха |
|---|---|---|---|---|
| E-1. Бэклог и иерархия рабочих элементов | CRUD рабочих элементов пяти типов, декомпозиция, циклы запрещены | Must | US-M1, US-L2, US-L6 | M4 |
| E-2. Канбан-доска и статусы | Визуальное управление статусом, настраиваемые статусы | Must | US-M2, US-A1 | M4 |
| E-3. Итерации и ёмкость | Планирование, базовый план, контроль загрузки, завершение | Must | US-L1, US-L3 | M4 |
| E-4. Учёт трудозатрат | Оценка, регистрация факта, расчёт остатка и перерасхода | Must | US-M3 | M4 |
| E-5. Совместная работа | Комментарии, вложения, встроенные уведомления | Must | US-M4, US-M5 | M4 |
| E-6. История изменений и аудит | Запись истории, diff-просмотр | Must | US-L4 | M4 |
| E-7. Жёсткое удаление | Безвозвратное удаление с защитой от потери дочерних элементов | Must | US-A2 | M4 |
| E-8. Интеграция с сервисом тестирования | Создание ошибок через API, идемпотентность | Must | US-T1 | M5 |
