## NFR-008: профиль измерения и утверждение

Task Tracker измеряет API work-items и reports/work-items: concurrency 1/5/20, одинаковый набор seed, успешные/ошибочные запросы, p50/p95 и throughput. Для масштабного прогона руководитель подтверждает объём пользователей/элементов; dev-seed не заменяет нагрузочный набор. UI измеряется E2E через браузер. Infra измеряет backup age (RPO) и длительность восстановления (RTO); доступность требует согласованного окна наблюдения. Результат сохраняется отдельным JSON, не подставляется в колонку порога автоматически.

До И-M2 Task Tracker + руководитель + Infra утверждают профиль, пороги, перегрузку и восстановление в DEC-TT-07. До этого NFR-008 partial; production-readiness и сдача этого требования не заявляются. Числа не выдумываются для смены статуса.
