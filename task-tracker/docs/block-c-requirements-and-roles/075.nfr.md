# 075 — NFR (Non-Functional Requirements)

> Формат — см. [`../documents-composition.md`](../documents-composition.md#075--nfr-non-functional-requirements-075nfrmd).
> Источник — [`../vision.md`](../vision.md), раздел «Нефункциональные требования». Рабочие ID
> введены в [095 — Traceability Matrix](095.requirements-check.md).

| ID | Категория | Требование | Метрика / порог |
|---|---|---|---|
| NFR-001 | Надёжность | Операции изменения данных сохраняют целостность или возвращают понятную ошибку | 100 % операций завершаются согласованно или откатываются целиком |
| NFR-002 | Сопровождаемость / аудит | Каждое изменение карточки фиксируется в истории с автором/источником, датой, изменёнными полями, старыми и новыми значениями | 100 % успешных изменений порождают запись истории |
| NFR-003 | Безопасность | Авторизация контролируется на сервере по роли пользователя, не только скрытием элементов интерфейса | Проверка прав на каждый запрос к API, независимо от клиента |
| NFR-004 | Надёжность | Уведомление создаётся только после успешного изменения и не должно теряться при штатной работе | Доставка во внутренний список уведомлений — без потерь при отсутствии сбоя инфраструктуры |
| NFR-005 | Целостность данных | Жёсткое удаление выполняется атомарно, без «повисших» ссылок | Удаление элемента и всех зависимых записей — в одной транзакции |
| NFR-006 | Наблюдаемость | Интеграционные операции наблюдаемы: результат, длительность, correlation ID; секреты не пишутся в журнал | 100 % внешних вызовов логируются без утечки секретов |
| NFR-007 | Удобство использования | Единый формат дат/времени и согласованный часовой пояс | Один формат и один часовой пояс во всех представлениях |
| NFR-008 | Производительность / доступность *(предварительно, требует согласования)* | Целевые время отклика, пропускная способность, объём данных, RPO/RTO резервного копирования | Значения не определены в `vision.md` — открытый вопрос, см. «Открытые решения» в vision.md |

Связь с архитектурными решениями — см. [145 ADR](145.architecture-decisions.md) (ADR-003 безопасность, ADR-005 удаление, ADR-006 кэш справочников).
