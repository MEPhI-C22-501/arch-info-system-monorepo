# 080 — User Stories: администратор

> Формат — см. [`../documents-composition.md`](../documents-composition.md#080--user-stories-080actor-user-storiesmd).
> Источник — [`../vision.md`](../vision.md). Роль — [070 RBAC](070.role-matrix.md), use cases — [060](../block-b-domain-analysis/060.use-cases.md).

**US-A1.** As an администратор, я хочу настраивать список статусов и их порядок, чтобы канбан-доска отражала реальный процесс команды.
- GWT-1: Дано я добавляю новый статус, Когда сохраняю изменение, Тогда новая колонка появляется на доске у всех пользователей.
- GWT-2: Дано модель прав согласована, Когда я изменяю разрешения роли или доступность одного из пяти типов, Тогда сервер применяет новую настройку ко всем последующим запросам; создать шестой тип нельзя.
*(→ UC-12)*

**US-A2.** As an администратор, я хочу жёстко удалить ошибочно созданный элемент, чтобы он не оставался ни в бэклоге, ни в отчётах.
- GWT-1: Дано элемент не имеет дочерних элементов, Когда я подтверждаю жёсткое удаление, Тогда элемент, комментарии, вложения, трудозатраты и история удаляются; уведомление исполнителю сохраняется без ссылки.
- GWT-2: Дано у элемента есть дочерние элементы, Когда я пытаюсь удалить его, Тогда операция блокируется до удаления или переноса дочерних элементов.
*(→ UC-15)*

**US-A3.** As an администратор, я хочу запускать синхронизацию справочников и видеть её ошибки, чтобы назначения используют актуальные оргданные.
- GWT-1: Дано сервис справочников доступен, Когда я запускаю синхронизацию, Тогда кэш обновляется и показывается время последнего успеха.
- GWT-2: Дано сервис недоступен, Когда синхронизация завершается ошибкой, Тогда существующие задачи читаются из последней успешной версии, а ошибка видна в журнале.
*(→ UC-18)*
