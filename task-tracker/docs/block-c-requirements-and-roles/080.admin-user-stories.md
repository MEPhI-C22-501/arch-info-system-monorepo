# 080 — User Stories: администратор

> Формат — см. [`../documents-composition.md`](../documents-composition.md#080--user-stories-080actor-user-storiesmd).
> Источник — [`../vision.md`](../vision.md). Роль — [070 RBAC](070.role-matrix.md), use cases — [060](../block-b-domain-analysis/060.use-cases.md).

**US-A1.** As an администратор, I want настраивать список статусов и их порядок so that канбан-доска отражала реальный процесс команды.
- GWT-1: Given я добавляю новый статус, When сохраняю изменение, Then новая колонка появляется на доске у всех пользователей.
- GWT-2: Given модель прав согласована, When я изменяю разрешения роли или доступность одного из пяти типов, Then сервер применяет новую настройку ко всем последующим запросам; создать шестой тип нельзя.
*(→ UC-12)*

**US-A2.** As an администратор, I want жёстко удалить ошибочно созданный элемент so that он не оставался ни в бэклоге, ни в отчётах.
- GWT-1: Given элемент не имеет дочерних элементов, When я подтверждаю жёсткое удаление, Then элемент, комментарии, вложения, трудозатраты и история удаляются; уведомление исполнителю сохраняется без ссылки.
- GWT-2: Given у элемента есть дочерние элементы, When я пытаюсь удалить его, Then операция блокируется до удаления или переноса дочерних элементов.
*(→ UC-15)*

**US-A3.** As an администратор, I want запускать синхронизацию справочников и видеть её ошибки so that назначения используют актуальные оргданные.
- GWT-1: Given сервис справочников доступен, When я запускаю синхронизацию, Then кэш обновляется и показывается время последнего успеха.
- GWT-2: Given сервис недоступен, When синхронизация завершается ошибкой, Then существующие задачи читаются из последней успешной версии, а ошибка видна в журнале.
*(→ UC-18)*
