# 080 — User Stories: участник команды

> Формат — см. [`../documents-composition.md`](../documents-composition.md#080--user-stories-080actor-user-storiesmd).
> Источник — [`../vision.md`](../vision.md). Роль — [070 RBAC](070.role-matrix.md), use cases — [060](../block-b-domain-analysis/060.use-cases.md).

**US-M1.** As a участник команды, I want видеть список назначенных мне рабочих элементов so that я понимал(а) свою текущую нагрузку.
- GWT-1: Given назначенные элементы существуют, When я открываю свой список задач, Then вижу все элементы с моим исполнителем, отсортированные по сроку.
- GWT-2: Given у меня нет назначенных элементов, When я открываю список, Then вижу явное сообщение об отсутствии задач.
*(→ UC-1)*

**US-M2.** As a участник команды, I want перемещать карточку между колонками канбан-доски so that отражать реальный статус выполнения.
- GWT-1: Given карточка в колонке «В работе», When я перетаскиваю её в «На проверке», Then статус сохраняется и создаётся запись истории.
- GWT-2: Given переход запрещён правилами процесса, When я пытаюсь его выполнить, Then система отменяет перемещение и поясняет причину.
*(→ UC-3)*

**US-M3.** As a участник команды, I want регистрировать фактически потраченное время so that фактическая трудоёмкость была верной.
- GWT-1: Given я указал(а) часы и дату, When я сохраняю запись, Then фактическая трудоёмкость увеличивается на указанные часы, а оставшееся время пересчитывается.
- GWT-2: Given факт уже превышает план, When я добавляю ещё часы, Then система показывает перерасход, а не нулевой остаток.
*(→ UC-7)*

**US-M4.** As a участник команды, I want получать уведомление при назначении на задачу so that не пропустить новую работу.
- GWT-1: Given меня назначили исполнителем, When назначение сохранено, Then я вижу новое непрочитанное уведомление со ссылкой на карточку.
- GWT-2: Given я являюсь текущим исполнителем, When карточка, комментарий, вложение, трудозатрата или связь успешно изменены, Then я получаю уведомление с автором, временем и описанием изменения.
- GWT-3: Given изменение завершилось ошибкой, When я открываю уведомления, Then уведомления об этой неуспешной операции нет.
*(→ UC-14)*

**US-M5.** As a участник команды, I want обсуждать работу и обмениваться вложениями в карточке so that контекст выполнения сохранялся рядом с задачей.
- GWT-1: Given карточка мне доступна, When я добавляю комментарий, Then он появляется в хронологическом списке с автором и временем.
- GWT-2: Given у меня есть право на вложения, When я загружаю файл, Then его можно увидеть и скачать; удаление доступно только при соответствующем праве.
*(→ UC-5, UC-6)*
