## Изменение статуса на канбан-доске

Связи: UC-3, US-M2, `PATCH /api/v1/work-items/{id}`.

```mermaid
sequenceDiagram
    actor U as Участник команды
    participant UI as SPA
    participant API as API Gateway
    participant WI as Work Item Service
    participant AUD as Audit Service
    participant NOT as Notification Service
    participant DB as PostgreSQL

    U->>UI: перетаскивает карточку в новую колонку
    UI->>API: PATCH /api/v1/work-items/{id} (status)
    API->>WI: изменить статус
    WI->>DB: BEGIN; update WORK_ITEM
    WI->>AUD: подготовить audit entry
    AUD->>DB: insert AUDIT_ENTRY
    WI->>NOT: подготовить notification
    NOT->>DB: insert NOTIFICATION
    alt переход допустим и все записи успешны
        WI->>DB: COMMIT
        WI-->>API: статус сохранён
        API-->>UI: 200 OK, новая карточка
        UI-->>U: карточка отображается в новой колонке
    else запрещённый переход или ошибка записи
        WI->>DB: ROLLBACK
        WI-->>API: 409/500 + correlationId
        API-->>UI: ошибка; исходное состояние
        UI-->>U: карточка возвращена с пояснением
    end
```

## Сервис тестирования создаёт ошибку

Связи: UC-16, US-T1, `POST /api/v1/bugs`.

```mermaid
sequenceDiagram
    participant T as Сервис тестирования
    participant API as API Gateway
    participant INT as Integration Service
    participant WI as Work Item Service
    participant AUD as Audit Service
    participant NOT as Notification Service

    T->>API: POST /api/v1/bugs (externalDefectId, severity, ...)
    API->>API: проверить token/scope и обязательные поля
    alt доступ или данные невалидны
        API-->>T: 401/403/422 + correlationId
    else запрос валиден
      API->>INT: проверить дубликат по (source, externalDefectId)
      alt дубликат найден
        INT-->>API: существующий workItemId
        API-->>T: 200 OK, already-exists
      else новый дефект
        INT->>WI: создать «Ошибку», severity → priority
        WI->>AUD: записать источник и externalDefectId в той же транзакции
        WI->>NOT: создать уведомление в той же транзакции, если назначен исполнитель
        WI-->>INT: workItemId
        INT-->>API: 201 Created
        API-->>T: 201 Created, workItemId
      end
    end
    Note over T,API: Клиент использует ограниченный timeout; безопасный retry идемпотентен по паре source + externalDefectId
```

## Сервис отчётности запрашивает данные

Связи: UC-17, US-R1, `GET /api/v1/reports/work-items`.

```mermaid
sequenceDiagram
    participant R as Сервис отчётности
    participant API as API Gateway
    participant WI as Work Item Service

    R->>API: GET /api/v1/reports/work-items?periodFrom=...&periodTo=...&page=1
    API->>API: проверить токен и scope (read-only)
    alt scope недостаточен
        API-->>R: 403 Forbidden
    else доступ разрешён
        API->>WI: выборка с фильтрами и пагинацией
        alt запрос выполнен
            WI-->>API: страница результатов
            API-->>R: 200 OK, items + пагинация
        else БД недоступна / timeout
            WI-->>API: ошибка
            API-->>R: 503/504 + correlationId
        end
    end
    Note over R,API: Клиент задаёт timeout; повтор безопасен, поскольку операция только читает данные
```

## Синхронизация справочника пользователей

Связи: UC-18, US-D1, US-A3; исходящий draft-контракт описан в [130](../block-g-api-and-events/130.api-contracts.md).

```mermaid
sequenceDiagram
    participant Sch as Планировщик (расписание) / Администратор (вручную)
    participant INT as Integration Service
    participant Refs as Сервис справочников
    participant Cache as Локальный кэш

    Sch->>INT: запустить синхронизацию
    INT->>Refs: GET directory snapshot (timeout, correlationId)
    alt сервис недоступен
        Refs-->>INT: timeout / ошибка
        INT->>Refs: ограниченный retry
        INT-->>Sch: ошибка синхронизации; старый кэш сохранён, ошибка видна администратору
    else успешный ответ
        Refs-->>INT: список пользователей/команд/подразделений
        INT->>Cache: обновить кэш, отметить время синхронизации
        INT-->>Sch: синхронизация завершена
    end
```
