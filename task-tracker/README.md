# Task Tracker

Система управления задачами для командной работы: бэклог, канбан-доска, итерации, декомпозиция задач, комментарии, учёт трудозатрат и обмен данными через Excel.

## Текущий статус

Проект находится на этапе проработки требований. Реализация и инструменты сборки пока не добавлены.

Планируемый стек:

- backend — Java и Spring Boot;
- frontend — React и TypeScript.

Подробные функциональные требования, бизнес-правила, сценарии и критерии приёмки описаны в [документе требований](docs/system-requirements.md).

## Разработка

Правила структуры проекта, качества кода, тестирования и оформления изменений приведены в [руководстве для участников](AGENTS.md). После добавления приложения этот раздел должен содержать точные команды локального запуска, сборки и тестирования.
